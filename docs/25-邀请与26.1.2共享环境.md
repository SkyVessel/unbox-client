# 邀请、共享环境与 26.1.2（2026-10-13）

## 本轮交付

- Minecraft 版本新增 26.1.2，保留 26.1；创建 Profile 默认选择 26.1.2。Fabric / NeoForge 使用分别编译的原生模块，共用功能源码，不做加载器转换。
- Fabric Loader 0.19.5；26.1.2 的 NeoForge 固定为 26.1.2.116。每个游戏版本独立锁定优化依赖与 Iris/Sodium 配对，避免把仅支持 26.1.2 的 Sodium 安装给 26.1。
- Mods / Packs / Shaders 可直接移除文件、打开对应目录；Profile 可删除。移除转存本地 removed 目录，可 Undo，运行中的 Profile 禁止删除，不直接销毁存档。
- 不需要先启动游戏才能接受邀请。启动器选择与房主版本、加载器相符的独立好友 Profile，完成同步并自动重启加入。正在运行的游戏通过本地桥接处理邀请；跨版本/加载器切换仍需重新启动游戏。
- 游戏内 Friends 页面支持好友码、加好友、接受/拒绝请求、邀请及离线好友显示。启动器与游戏内邀请通知保留原列表条目，处理成功后隐藏通知。
- 邀请采用头像、玩家 ID、世界名（好友请求为 Friend request），右侧 Join/Accept 与 Decline。按用户追加意见，启动器由约 420×69 缩为 276×34；游戏内等比缩到 0.56 倍，占屏面积约为之前 31.4%。保留短暂缩放浮现，支持减少动态效果。

## 共享哪些内容

Manifest schema 2 同步普通玩法 JAR、resourcepacks/*.zip、shaderpacks/*.zip，以及资源包启用顺序、Iris 的 shaderPack / enableShaders。内置个人 Client Mods 不列入共享玩法；快捷键、HUD 和其他个人配置不被房主覆盖。朋友 Profile 与自己的世界 Profile 隔离。

文件按 SHA-256 校验并缓存；未改变的文件不再传输。文件修改和移除均按房主清单更新。大文件哈希、读取和传输在后台工作线程，不放在每帧渲染中。启用选择变化也会触发必要的准备和重启。

边界：只支持 ZIP 形式的材质/光影包，不是完整整合包 config、脚本、解压目录包或世界存档复制。光影包独立的高级参数文件尚未同步。最多 512 个共享文件、单文件 512 MiB、总计 4 GiB；不是无限大整合包或断点续传承诺。旧 schema 1 游戏模块需要双方更新后使用新同步。

## 名字徽章与原版联机

Unbox 房主通过 Fabric/NeoForge 可选数据通道识别实际支持 Unbox 的玩家，向支持该通道的访客发送名单。名字前缀采用原始开盒透明图形的 96px 字体纹理，与原版名字同一文字布局及深度渲染，不独立画漂浮面板；不继承徽章字体到玩家姓名。

普通原版客户端没有该通道，因此没有徽章，也不会因缺少通道而断线。在不运行 Unbox 服务逻辑的第三方服务器上，不猜测其他玩家的客户端身份，不凭昵称或好友身份加徽章。

普通 Multiplayer 地址 / LAN 与 Unbox 私密邀请不同：前者兼容同版本原版玩家（游戏内容也须兼容），后者的认证和自动同步需要 Unbox。含新增内容的玩法模组服务器仍要求访客安装相同内容，原版客户端不能凭空支持模组物品。

## 已完成验证

- `npm test`：40 项通过，包含删除/Undo、内容目录入口、无运行 Profile 的邀请路由、紧凑通知及面积上限。
- Rust：35 项通过，包含隔离 Profile、版本/加载器校验、缓存校验、包路径拒绝、启用顺序、删除旧包与保留个人按键。
- 26.1.2 Fabric / NeoForge 各 130 项实际游戏 UI 检查通过；缩小后 Fabric 又完成 130 项，验证点击坐标与缩放一致。
- 26.1 Fabric / NeoForge 各 25 项标题页回归通过。NeoForge 首次后台运行遇到测试对动画帧的时序假设，改为等待实际动画完成后复测通过；未改生产动画时长。
- 两种 26.1.2 加载器分别运行两个真实游戏进程。仅房主安装测试玩法 JAR、自建材质 ZIP、最小直通光影 ZIP；访客零 Profile 开始，下载、原生准备、重启后加入，两边真实使用新增物品并收到服务器奖励。访客资源管理器确认材质已加载，Iris API 确认光影已启用。首次传输约 2.10 MB；两者再次加入均 0 字节、不重启。
- 徽章能力名单在双客户端检查中通过，并实际截图检查了名字前图形、基线与姓名字体。
- 未修改的 Mojang 26.1.2 客户端（没有 Unbox 或任何模组）分别加入 Fabric / NeoForge 的普通 LAN 世界，维持 100 tick，收到服务器聊天消息，确认没有 Unbox 徽章。

证据位于 `.cache/network-tests/packs2612-fabric-02.json`、`packs2612-neo-01.json`、`badge2612-fabric-01.json`，以及 `.cache/benchmarks/compact2612-*/logs/ui-smoke.json`、`tiny-popup2612-fabric-01/logs/ui-smoke.json`、`vanilla-lan2612-*/logs/vanilla-interop.json`。

这些是 macOS 同机隔离实测；好友服务测试使用本地 Cloudflare 兼容服务。原版联机检查使用明确的本地离线测试身份，未替代两位正版账号通过官方启动器登录的实测，也不是异地家庭网络、Windows 游戏、商业光影或大型整合包性能测试。背景窗口的 Dynamic FPS 限速不是前台性能结果；本轮不声称 FPS 提升。

## 云端与发布

本机 Cloudflare MCP 已可调用，已更新 Workers Free 的现有好友 Worker，使房间元数据支持 Fabric / NeoForge、26.1 / 26.1.2。没有付费资源变更，也没有读取/复制账户密钥。

本地 macOS 调试应用已构建，四份模块与源码构建产物逐字节核对一致；云端健康检查 HTTP 200。本轮交付本地 macOS 调试应用，GitHub 公开 latest 仍为 v0.2.6，尚未发布本轮改动。Windows 构建流程已补充两份 26.1.2 JAR 及校验摘要输入，但未运行本轮 Windows 构建。
