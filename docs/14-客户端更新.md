# 客户端手动更新

入口：左下角无边框下载图标，或 Settings → Updates → Check for updates。当前没有发布包时显示 No releases published yet。不会在启动或游玩期间自动安装。

检查稳定版 GitHub Release，读取该版的 latest.json，按当前平台和版本选择更新。用户点击 Install and restart 才下载；Tauri 校验签名后替换应用并重启。游戏运行或下载游戏时禁止安装；原生层与启动游戏共享任务锁，避免同时开始。下载失败可重试，Profile 与存档在应用数据目录中，不在被替换的应用包内。

## 发布配置

- 当前发布版本 0.2.0；package.json、Cargo.toml、tauri.conf.json、锁文件和游戏模块版本保持一致。
- 更新签名私钥保存在本机 `~/.config/unbox/updater.key`，文件权限 0600。请安全备份，不能提交 Git、上传为 Release 附件或放进前端。对应公钥已写入 Tauri 配置。此签名不等同于 Apple Developer 签名/公证。
- 之后得到发布指令时，设置 `TAURI_SIGNING_PRIVATE_KEY` 为该私钥文件绝对路径，使用 `npm run tauri -- build --config src-tauri/tauri.updater.conf.json` 生成签名更新产物。普通调试构建不启用此覆盖配置。
- macOS 上传 `.app.tar.gz`、其 `.sig` 以及 `latest.json` 到同一个稳定 Release。manifest 的 signature 使用 `.sig` 文件内容；URL 必须指向本仓库该 Release 的附件。
- 首版目标为 `darwin-aarch64`，不能把 ARM 包冒充 Intel/Windows/Linux 包。其他平台须分别构建和验证。

latest.json 结构示意（占位内容不能直接发布）：

```json
{
  "version": "0.2.0",
  "notes": "Release notes",
  "pub_date": "2026-10-08T00:00:00Z",
  "platforms": {
    "darwin-aarch64": {
      "signature": "CONTENTS_OF_SIG_FILE",
      "url": "https://github.com/SkyVessel/unbox-client/releases/download/v0.2.0/ACTUAL_APP_ARCHIVE.app.tar.gz"
    }
  }
}
```
