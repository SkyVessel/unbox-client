# Unbox：玩家市场、第三方客户端与盈利方案

调查日期：2026-10-14。结论基于公开资料；未取得任何公司的内部订单、月度财报或付费用户数据。本文与 [模组选型及原型报告](27-Mod选型与UI原型.md)配套。

## 1. 能否给出全体玩家的 PvP / 生存 / 联机 / 单人比例？

**目前查不到足以支持“2026 年全球玩家中各占多少”的公开代表性数据，因此无法负责任地给出纯单人玩家的大致总人数。** 这几个分类本身也重叠：一个人既可以玩生存也可以 PvP，既可以单人也可以联机；生存服务器也可能开启 PvP。不能把四个数凑成 100%。

已核验的规模锚点：

- Minecraft 官方记录 **2023 年累计销量超过 3 亿份**。这是历史累计售出份数，不是当前活跃人数，也不等于 Java 玩家数。[官方周年回顾](https://www.minecraft.net/en-us/15th-anniversary)
- Xbox 2021 年官方 fact sheet 的公开索引给出接近 1.4 亿月活；这是历史全平台指标，本轮 PDF 正文抓取失败，不把它当作当前规模基数。[官方资料地址](https://news.xbox.com/en-us/wp-content/uploads/sites/2/2021/04/Minecraft-Franchise-Fact-Sheet_April-2021.pdf)
- Lunar 收购 Badlion 的官方公告称两者**合计超过 300 万月活**。它是公告时口径，不能当作 2026-10 的实时数字，也未说明跨客户端是否充分去重，更不能拆成 Lunar 单独 300 万。[收购公告](https://www.lunarclient.com/news/lunar-client-acquires-badlion-client)

最有参考价值的公开行为样本，是 [Lunar 2025 Wrapped](https://wrapped.lunarclient.com/leaderboards/2025/global)：

| 指标 | 官方记录 | 可计算但有限的含义 |
| --- | ---: | --- |
| 服务器进入次数 | 350,532,920 | 占三类进入事件合计的 84.78% |
| 单人世界进入次数 | 52,126,308 | 占 12.61% |
| Realms 进入次数 | 10,826,062 | 占 2.62% |
| 标为 PvP 的服务器进入次数 | 59,322,731 | 约等于服务器进入总次数的 16.92% |
| 标为 Survival 的服务器进入次数 | 19,801,370 | 同口径约 5.65% |

上述三类事件合计 413,485,290；百分比是本报告计算。**不是人数占比，不是游玩时长，也不是全球 Minecraft 占比。** 官方未在页面给出完整分类与去重方法；Minigames 可能包含 PvP，Survival 也不能证明完全没有 PvP。单人进入事件可能来自同时玩服务器的人。因此既不能用 12.61% 推算“纯单人玩家”，也不能拿服务器总数减 PvP 标签数推算“非 PvP 联机”。Lunar 用户本身还是客户端选择后的偏向样本。

本次还查到旧论坛投票、捷克地区旧调查、特定服务器社区调查；样本年代、地区或自选择偏差太大，未将它们升级成当前全球估计。网站在线计数、模组下载数同样不能作为月活去重人数。

**对 Unbox 的判断：** 生存/建造方向值得做，理由是可明确定位的用户任务与付费价值，不是已经证明这类玩家占全体的某个比例。你的可服务市场应收窄为“支持目标版本和系统的 Java 玩家，愿意安装客户端，在意自己的长期世界或经常与朋友一起玩”。Bedrock、主机和手机的大量玩家不能直接计入。

验证方法：先从 2–8 人朋友生存小组、长期单人生存、建筑投影用户分别招募测试。问最近 30 天是否玩 PvP、是否非 PvP 联机、是否纯单人；玩法和社交两个维度分开记录。自愿匿名使用数据记录成功启动、成功加入、同一世界回访与功能使用，不上传世界内容或聊天。首批 200–400 份跨社区样本能帮助产品选择，但便利样本不能宣传成全网比例。

## 2. 为什么玩家使用第三方启动器／客户端？

下表的“选择动机”是根据厂商功能和任务成本作出的产品推断，并非本轮玩家问卷得出的因果结论。

| 产品 | 核实的核心能力 | 可能吸引用户的原因 | 已确认的收入路径 |
| --- | --- | --- | --- |
| Lunar / Badlion | 集成 HUD/游戏模块、版本启动、社交、外观 | 少安装和调试，习惯固定设置，好友/创作者带动，展示身份 | 外观/表情与 Coins、Lunar+、托管合作入口；各渠道金额未披露 |
| 原版 Feather | 自装模组、HUD、自家电脑开服及代理网络、语音、皮肤库 | 把“装模组＋和朋友一起玩”合并，减少开服门槛 | 官方 2024 商店公告改为 Points 购买外观；服务器合作外观。当前官网已公告迁移 Dawn |
| Essential | 在现有 Minecraft/整合包里邀请朋友、社交与外观 | 保留原整合包，快速一起玩，社交外观 | Coins 买外观/表情、赠礼与创作者代码分成 |
| Prism Launcher | 多实例、整合包/模组管理、低资源占用 | 高控制权、清晰隔离、可复现，适合复杂整合包 | 捐助和赞助；不是所有启动器都靠卖外观 |
| Modrinth App | 内容发现、安装、实例管理 | 查找内容到安装的路径短，来源集中 | 本轮仅纳入产品能力比较，不对其收入结构或金额作未核验推断 |

来源：[Lunar 官网](https://www.lunarclient.com/)、[Feather 官网](https://feathermc.com/)、[Feather 商店更新](https://news.feathermc.com/store-update/)、[Feather 合作说明](https://partner-wiki.feathermc.com/en/server-partnership/server-information/)、[Essential 官网](https://essential.gg/)、[Essential Coins](https://essential.gg/en/wiki/essential-coins)、[Prism 官网](https://prismlauncher.org/)、[Modrinth App](https://modrinth.com/app)。厂商的 FPS 宣传未在本轮独立复测，不作为 Unbox 可达到的性能保证。

**市场变化：** Feather 官网目前明确写着被 InPvP 收购并迁移 Dawn，不能继续把原 Feather 当作完全独立运营的现状。你不喜欢 Dawn 的视觉偏好仍然遵守；本轮 UI 不参考 Dawn，商业调查中仅说明这项事实。Lunar 已收购 Badlion，两者不能简单当成两个完全独立的竞品公司相加。

Lunar 当前的 [Lunar+ 页面](https://store.lunarclient.com/category/plus)列出 **US$6.99/月起**，包括专属外观、每月表情、商城优惠、好友/群聊权益等。[Coins 公告](https://www.lunarclient.com/news/introducing-coins-your-new-way-to-buy-cosmetics)说明虚拟币购买外观与表情、赠送机制和部分商品不能用 Coins 支付。它的官网有 Apex Hosting 合作链接，但具体分成率与收益未公开。

## 3. 月营收到底能估到什么程度？

**Lunar 单品牌、Feather 和 Essential 的真实月营收，本轮均未找到可核验披露。** 未发现能支撑可信窄区间的 MAU、月付费率、每月付费用户消费额三项数据。网站估值工具的“假设投放广告可赚多少”、第三方企业数据库投影、收购金额都不能冒充月销售额。Feather 的当前品牌迁移又使历史和现行收入边界不同。

可以做的是规划用的**敏感性模型，不能称作公司营收估计**：

月用户销售流水 ≈ 月活用户数 × 当月付费用户比例 × 每位付费用户当月总消费。

这里的总消费已经包含订阅与一次性外观，不能再把同一批订阅收入额外加一遍。Coins 充值流水与外观消耗也不能重复记账；会计收入确认和用户付款流水不一定同月。

| 假设情景 | 月付费率（假设） | 月付费用户消费（假设） | 每 10 万 MAU 的月流水 | 代入 300 万规模的月流水 |
| --- | ---: | ---: | ---: | ---: |
| 低 | 0.5% | US$8 | US$4,000 | US$120,000 |
| 中 | 1.5% | US$12 | US$18,000 | US$540,000 |
| 高 | 3% | US$20 | US$60,000 | US$1,800,000 |

最后一列只是将公告中的合计用户量级代入同一公式，**不是 Lunar 的实际值、预测值或置信区间**。Feather 没有可信 MAU，不为它强行填写一个看起来精确的月收入。建模只说明：即使客户端免费，百万月活规模加少量付费也可能产生可观流水；反过来，几千活跃用户的客户端不能照搬其营收体量。

流水还要扣除税费、支付/渠道费、退款、创作者分成、基础设施、客服和开发成本；剩下才可能形成利润。第三方模组是免费安装，并不意味着客户端的维护与联机服务免费运营。

## 4. Unbox 应该怎么盈利？

建议产品承诺集中为：**“保住自己的世界，和朋友顺利开始玩，建造时少做重复操作。”** 更多模组是实现手段；更有区分度的是跨版本世界库、一次邀请完成环境准备、保留个人设置、出错可恢复，以及稳定一致的游戏内入口。

| 层级 | 建议内容 | 收费思路 | 必须跑通的闭环 |
| --- | --- | --- | --- |
| 免费核心 | 启动、基础性能、个人 HUD、小地图/整理等许可允许的集成、基础朋友联机、本地备份与恢复 | 免费 | 首次安装到进世界；失败有恢复；退出朋友房间保留自己的环境 |
| 托管服务 | 限量云备份、更长历史、跨设备恢复；可选的持久在线服务器 | 按容量/保留期或主机规格定价；先验证成本再售卖 | 备份成功校验、列版本、恢复副本、取消订阅、数据导出、保留期提醒；不把免费 Cloudflare 当无限中继/Java主机 |
| 支持者计划 | 自愿支持开发、原创身份展示；付费权益需确认许可 | 可先测试 US$3–5/月的接受度，属提案 | 明确权益、支付成功核验、跨设备恢复权益、退款/取消、账号稳定身份 |
| 原创外观 | 适合建造社群的原创外观与赠礼 | 单件明码标价，优先验证 US$3–8 的接受度；避免先做复杂虚拟币 | 真正3D预览、可见范围说明、服务端所有权、装备/卸下、禁用外观、离线缓存 |
| 托管推荐 | 用户确实需要 24/7 时推荐合作主机 | 可披露的推荐佣金 | 说明合作关系，价格与服务提供方清楚，不影响免费本机联机 |

价格全部是待验证提案，不是从竞品销量证明的最优价格。纯单人用户的朋友可见外观价值较低，备份、版本迁移与建造资料管理更贴近其需要；小组用户则更在意房主离线后能否继续、进入成功率和长期世界可靠性。

商业边界有一项直接影响你的披风计划：[Minecraft EULA](https://www.minecraft.net/en-us/eula)对通过 Mods 获利存在限制；[Usage Guidelines 的服务器与托管部分](https://www.minecraft.net/en-us/usage-guidelines)明确把披风及仿披风排除在允许售卖的服务器外观之外。这一段的范围是服务器，不能机械地据此给整个独立客户端作完整法律结论，但足以说明**别人有披风商店不等于 Unbox 自动获得相同许可**。因此本轮自有披风保留为功能/视觉草案，不把“卖披风”列为已确认可上线的首要营收；具体商业结构、资产与授权明确后才设收费权益。动态光源和地图的独立分发许可见报告 27。

## 5. 接下来怎样验证，而不是只留想法？

1. **第一阶段：当前原型评审与四组合技术试接。** 每个模组的许可、安装、卸载、失败恢复有明确验收；先不建商城。
2. **第二阶段：约 30 个真实朋友小组试用两周。** 招募目标是研究计划，非已经招募。记录从邀请到进入的成功率、耗时、退出后原环境恢复、连续两周同世界回访；同时记录模组冲突和客服耗时。单人测试单列。
3. **第三阶段：验证付费意愿。** 将云备份/持久主机/支持者三种方案以清楚价格给用户选择，区分“口头感兴趣”和实际付费；未提供服务之前不承诺已开通。
4. **第四阶段：限量收费试点。** 先跑通购买、权益、取消、退款、导出、成本监控。以贡献利润和保留用户数作决策，不以注册数或充值总额代替。

Unbox 的简化订阅模型（假定 US$4/月，仅作预算）：

| 月活 | 付费率 | 订阅者 | 月订阅流水 |
| ---: | ---: | ---: | ---: |
| 1,000 | 1% | 10 | US$40 |
| 10,000 | 2% | 200 | US$800 |
| 50,000 | 3% | 1,500 | US$6,000 |

保本订阅者数 = 月固定成本 ÷（订阅价格扣除税费/支付/退款后的实收 − 每个订阅者的月变动成本）。纯示例：月固定成本 US$2,000，每名实收 US$3.60，变动成本 US$1，则约需 770 名订阅者；若付费率为 2%，约需 38,500 MAU。所有成本值是假设，必须用真实备份容量、出口流量和客服数据替换。

结项范围：公开资料调查和商业假设已写明；尚无代表性全球比例、竞品真实财报、Unbox 用户测试或付费试验。没有将推测写成已经验证的市场事实。
