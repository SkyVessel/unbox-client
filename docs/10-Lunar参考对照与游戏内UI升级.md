# Lunar 参考对照与游戏内 UI 升级

日期：2026-10-07。目标版本：Minecraft Java 26.1 / Fabric。本轮在实际游戏内实现，不是静态原型。

## 参考的使用方式

阅读用户提供的《Lunar_Client_UI_Reference_ZH.pdf》共 58 页；重点查看准星、按键、盔甲、粒子、Freelook 和 HUD 设置截图。PDF 混合历史版本与功能说明，不能把其中的列表当成 26.1 可用性证明，也不能据此宣称已覆盖 Lunar 的所有模块。

另核对官方功能字段：[Crosshair](https://lunarclient.dev/apollo/developers/mods/crosshair)、[Particle Changer](https://lunarclient.dev/apollo/developers/mods/particlechanger)、[Keystrokes](https://lunarclient.dev/apollo/developers/mods/keystrokes)、[Armor Status](https://lunarclient.dev/apollo/developers/mods/armorstatus)。这些是 Apollo 服务器 API 文档，并不等于完整客户端设置目录。准星的视觉预设、分组和预览主要参照用户截图；不根据少量 API 字段推断客户端只有这些功能。

用户后续两张图片补充了重要层级：游戏主菜单，以及世界内 Right Shift 的小型快捷菜单。第二张是裁剪图，按第一张的屏幕占比理解。没有复制 Lunar 的品牌、贴图或闭源实现。

## 入口与视觉

- 游戏启动：原版全景背景与模糊上显示 Unbox 开盒标志、Singleplayer / Multiplayer；底部提供 Client Mods、Skin settings、Game settings。按钮真实连接世界选择、服务器入口和原版设置，并保留多人游戏安全提示与账户限制。
- 世界中 Right Shift：先显示小型居中快捷菜单，Mods 为主要入口，两侧是 Edit HUD 与 Game settings；再次按 Right Shift 返回游戏。Mods 关闭后返回快捷菜单。
- 主菜单与快捷菜单按屏幕宽高等比约束，避免 GUI Scale 改变后铺满屏幕。主菜单主要按钮宽度约占普通 16:9 窗口的 23%。
- 黑白灰为主，蓝色用于选择、开关和焦点；红色用于关闭悬停及警告。启动器也同步改色。在线状态的语义绿色和此前指定的橙色 Playing 状态保留。背景风景和游戏物品的原有颜色不做强制去色。
- 继续使用 Barlow、高分辨率字形与抗锯齿圆角。面板文字改为整段批量提交，复用有上限的布局缓存。没有引入浏览器内核渲染游戏 UI。

## 已知边界

- 当前有 13 个模块入口，并非 Lunar 的完整模块集合。护甲仍作为整体移动，尚未实现每个装备槽独立定位。
- 粒子密度为 0–100% 的保留率，没有实现 Lunar 文档中的大于原数量的复制倍率。透明度路径覆盖单四边形粒子，其他渲染类型没有承诺一致支持。
- 准星对比背景是简单色块，粒子侧栏是标注为 Sample 的预览；不冒充实际游戏效果截图。真实粒子行为另外用游戏断言验证。
- Singleplayer、服务器列表、游戏选项及皮肤图层开关仍使用原版功能页面；尚未把所有原版二级页面重绘。Skin settings 不等于皮肤上传或更换服务。
- 正版账号、OptiFine 披风网络和多人服务器限制仍需要对应真实账号/服务器验证；本轮本地身份的 Realms 401 不属于 UI 功能通过证据。
- 没有在本机运行 Lunar/Feather 做同场景性能对比，也不宣称已经达到其所有功能与成熟度。

## 验证记录

最终构建、真实游戏截图、断言及性能原始文件见 `design/exports/in-game-v4/` 与 `research/benchmarks/2026-10-07-lunar-v4/`。所有世界测试都在副本中进行，未打开原存档写入。

游戏内最终回归：101 项通过。覆盖入口导航、13 个设置页渲染、数值和颜色取消、跨标签搜索、真实粒子过滤/寿命/透明度、HUD 拖动与锁定、护甲数据和布局、Keystrokes、实际 Freelook 相机运动、Zoom 视场和滚轮、GUI Scale 2/4/6、Sodium 设置入口。渲染页面通过与实际行为通过在报告中逐项区分。

本轮还发现并修复了首次进入世界之前，护甲预览创建 ItemStack 导致 `Components not bound yet` 的崩溃。未加载世界时不构建设备预览数据，相关入口受限，增加标题菜单回归覆盖。

主菜单最终回归：20 项通过；包括启动替换、实际世界/服务器/设置导航、未进世界护甲安全、GUI 6 和 1000×650 / 1600×900 窗口。Node/Playwright：9 项通过；macOS 原生应用构建通过。

性能：同一台 Mac、2560×1440、视距 12、模拟距离 8、固定场景、预热 30 秒/采样 45 秒、相同优化模组和 HUD，按旧 → 新 → 新 → 旧测量。旧版平均 340–341 FPS、1% Low 138–139；新版平均 333–335 FPS、1% Low 131–133。存在约 1.3–2.3% 平均帧率和约 3.6–5.8% 1% Low 的小幅下降，不能称为性能提升。根因尚未隔离，帧稳定性仍是未闭环项；原始帧时间、哈希和逐次数字在性能目录。未对大型整合包、跑图或多人场景作泛化承诺。


## v4.1 小修订：尺寸、Logo、动效与应用图标

- 游戏主菜单、右 Shift 快捷菜单和 Mods 面板相对上一版统一缩小 15%，Mods 面板水平居中。HUD 编辑采用原有独立坐标和大小，已保存的位置不迁移、不重置。
- 原 Logo SVG 使用深灰填充作为遮挡面，直接导出会把这些面变成黑块。保持原路径和遮挡关系，改用亮度蒙版输出透明轮廓；游戏资源由 96×96 提升为 768×768，并匹配纹理采样尺寸。启动器共用 SVG 同步修正。
- 主菜单/快捷菜单/Mods 每次进入用 200ms 缓出淡入、12 个逻辑像素上移；结束后不继续播放。设置更新和窗口缩放不会反复触发，点击坐标匹配当前动画偏移。Minecraft Screen Effects 为 0 时跳过动画。
- macOS 应用图标采用 #101012 黑色圆角底板、白色透明轮廓；重新生成 PNG、iconset 和 ICNS。
- 同一最终 JAR 的主菜单测试 23 项、游戏内测试 101 项通过。Logo 全图像素检查：768×768，487253 个完全透明像素，可见深色像素为 0。应用图标底板采样 RGBA 为 16/16/18/255。
- 真实游戏截图、构建哈希和报告在 `design/exports/in-game-v4.1/`。本次未重新测量 FPS，不将纯视觉修订报告为性能提升。
