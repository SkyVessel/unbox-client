# 0.2.6 测试更新发布

2026-10-10，用户授权将最新修复上传 GitHub，供其他测试者使用内置更新。已公开发布 https://github.com/SkyVessel/unbox-client/releases/tag/v0.2.6 ，GitHub latest 指向此版；源码提交 `b7d9628a216bff9829649d1d2f57e1062ab1ec62`。

包含此前未公开的标题 Esc 返回修复、原生 NeoForge、共享玩法模组、好友显示与缓存、地图/延迟 HUD、改键及完整设置目录、自有 Microsoft 应用接入。旧 DevLogin 账号需要重新授权；不把设备码请求成功当作真人完整登录通过。
