# 0.2.11 更新发布

2026-10-19，已公开发布 [v0.2.11](https://github.com/SkyVessel/unbox-client/releases/tag/v0.2.11)，并设为 GitHub latest。标签指向 `15b0601e56b7cad44cb13a21414c087b620d81b8`，源码已推送 main。

## 本次内容

- 文档 47–49 的账号／资产后台、本地身份迁移、News、更新入口、皮肤界面和 Particles 移除。
- 修复 Mouse Tweaks 关闭后仍响应首次背包操作、重开界面后重新生效的问题；保留四项细分设置联动。
- 发布检查修复旧邮箱 UUID 记录阻止迁移后的本地账号注册私密联机身份的问题；保留 UUID 和存档身份，不授予旧云端身份或资产。
- 保留 Windows 启动器及同步／异步后台进程的小黑窗修复。
- 支持 26.1 / 26.1.2 / 26.3 × Fabric / NeoForge。

- macOS ARM64：`Unbox.Client_0.2.11_aarch64.app.tar.gz`，52,567,126 字节。
- Windows x64：`Unbox.Client_0.2.11_windows-x64-setup.exe`，31,300,098 字节。
- 两平台签名、更新清单、SHA-256 清单及六份游戏模块，共 12 个公开附件。移植源码归档与许可继续内嵌分发。
- 沿用原 updater 公钥；签名私钥只在发布机器使用，未上传 CI 或仓库。继续使用测试构建与 macOS ad-hoc 签名，没有 Apple 公证或 Windows 发布者签名；不含 Intel Mac/Linux 包。

## 更新与剩余验证

关闭 Minecraft 后，在旧版启动器进入 Settings → Updates → Check for updates → Install and restart。新版检测到更新时也会显示蓝色更新按钮。双方都需更新后使用新版私密联机；旧邮箱迁移后可能需要重新添加好友。应用更新保留独立数据目录中的 Profile 和世界。

Windows 游戏实玩、两个家庭网络联机与实际延迟、同事电脑上的应用自替换尚未实测；异地测试由用户按文档 48 执行。发布证据位于 `research/verification/2026-10-19-release-0211/`，不包含凭证、数据库原始备份或临时邀请密钥。
