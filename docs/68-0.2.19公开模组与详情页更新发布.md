# 0.2.19 公开模组与详情页更新发布

2026-10-23（本地日期），[Unbox Client 0.2.19](https://github.com/SkyVessel/unbox-client/releases/tag/v0.2.19) 已发布为 GitHub latest，提供 macOS ARM64 / Windows x64 启动器更新。源码和两平台构建提交为 `fd03cb33ff955d59938213d834dc916cfb6cccd5`。

## 本轮内容

- 自制 Freecam 替换为公开 Freecam 1.5.1，保留原按键迁移、滚轮速度和私密联机范围限制；关闭时在输入入口阻止启动。其他自制功能的保留原因见 docs/67，本轮未宣称全部替换。
- Discover 全目录浏览、完整 Modrinth 介绍和图片、详情内安装、缺图回退及返回时保留筛选状态，见 docs/66。
- 更新失败显示底层错误和 macOS 文件夹访问提示，见 docs/65。此改动在安装新版后生效；旧版若仍无法自动安装，可从 Release 手动下载安装。
- 六套 Fabric / NeoForge 模块版本均为 0.2.19，覆盖 Minecraft 26.1 / 26.1.2 / 26.3。

## 验证

- Node 70 项通过；macOS Rust 81 项通过、2 项显式公网测试跳过。
- 六模块重新编译及打包预检通过；所有 .class 字节与此前六环境各 32 项静默运行验证的构建一致，版本元数据单独核对为 0.2.19。
- macOS 应用与解包后应用 ad-hoc codesign 验证通过；并非 Developer ID 公证。
- [Windows 构建](https://github.com/SkyVessel/unbox-client/actions/runs/40055159667)通过，Rust 82 项通过、3 项跳过（含由后台进程测试调用的辅助探针）；GUI 子系统与两项后台无控制台测试通过。未做 Windows 游戏实玩。
- 两平台各 46 份资源核对通过；Windows JSON 仅允许 Git 换行差异。沿用原 updater 公钥，两个签名有效且篡改包均被拒绝。
- latest.json 和全部 12 个公开附件已匿名下载、核对 SHA-256，两平台公开下载包再次验证签名。
- 本轮检查、构建保持静默，没有打开可见的游戏或启动器，没有修改玩家 Profile / 存档。

## 建议验收

1. 启动器检查更新并安装，重启后确认 0.2.19。
2. 自己的 Profile 启动游戏，检查 Freecam 关闭时快捷键无响应，启用后移动、滚轮速度、玩家本体和原生设置正常。
3. 从侧栏 Discover 浏览全部目录，打开项目介绍，检查图片、返回后的筛选及安装到自己 Profile 的流程。
4. 若旧版受 macOS 文件夹权限影响无法更新，使用 Release 下载包手动更新；保留用户数据目录。
