# 1.8.9 自动疾跑与 0.2.26 快速发布

2026-11-15。用户明确要求修改有 UI 的 1.8.9、跳过所有测试，直接构建并发布 Windows 更新。

- `PvpControls` 删除按 LCtrl 切换疾跑和 tick END 强制恢复疾跑的逻辑。
- 新增 `SprintMixin`，在原版 `EntityPlayerSP.onLivingUpdate` 内读取疾跑按键时，按 Auto Sprint 模组状态提供持续疾跑意图。保留原版的移动、饥饿、使用物品、失明和碰撞判断；不添加网络包。
- 模组开启时清空并屏蔽 `sprintToggleTimer` 的读取，禁用双击 W 触发。关闭模组时保留原版按键和双击 W 行为。
- 模组名称改为 Auto Sprint，更新说明，删除 Activation key 行。HUD 状态取实际疾跑状态。
- Clean Test 和其他游戏版本不修改。

不运行自动测试、游戏测试、安装器测试。Java/前端/Rust 编译和更新包签名属于构建交付步骤，不作为功能测试通过的证据。此版本需由用户实玩验证新行为，不宣称已经解决此前的全部击退问题。

源码分支 `codex/auto-sprint-0.2.26`；独立发布工作目录 `.cache/release-0.2.26/source`。构建产物和签名记录在 `.cache/release-0.2.26/`。旧的显式游戏探针对“手动切换 Sprint”的假设已不适用于本次语义，后续恢复相关测试时须同步调整。
