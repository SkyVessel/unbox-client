# Microsoft 好友认证：玩家证书验证

## 原因与边界

2026-10-08 线上测试确认 Workers 调用 Mojang hasJoined 与 Minecraft profile 均返回 403 HTML「The request is blocked」，相同无会话查询在本机返回预期 204 / 401。官方问题记录：https://bugs-legacy.mojang.com/browse/WEB-7187 。不能将云端出口拒绝误报为用户没有正版账号，不能直接信任客户端声称的 UUID。

## 0.2.3 实现

客户端向 `https://api.minecraftservices.com/player/certificates` 请求官方玩家证书。令牌仅发送给 Minecraft 官方；证书私钥只在启动器进程内用于签署短期好友挑战，不发往 Cloudflare，不落盘、不暴露给前端。Cloudflare 只接收公开证书和挑战签名。

验证两层签名：

1. 用官方 `playerCertificateKeys` 验证 v2 证书签名（UUID 16 字节 + 过期时间 i64 大端 + 玩家 SPKI 公钥），拒绝过期、伪造、错误 UUID。使用 Mojang 协议规定的 RSA-SHA1 验证官方证书，不能自行换算法。
2. 用证书中的玩家公钥验证 RSA-SHA256 挑战签名。签名消息包含固定 Unbox 域标识、好友身份 ID、好友令牌哈希、120 秒随机挑战、游戏 UUID。不能复用于其他身份、令牌或挑战。只有此验证通过才创建 Microsoft 好友身份。

官方根公钥从 `https://api.minecraftservices.com/publickeys` 于 2026-10-08 获取并固定在 Worker 中；绝不接受客户端提供的根公钥。官方轮换根密钥时须从官方 HTTPS 来源重新核对后更新。身份与权限绑定 UUID，不依赖显示昵称。

实现协议核对：[PrismarineJS 服务端证书验证](https://github.com/PrismarineJS/node-minecraft-protocol/blob/master/src/server/login.js)、[证书 API 请求及格式](https://github.com/PrismarineJS/prismarine-auth/blob/master/src/TokenManagers/MinecraftJavaTokenManager.js)。实现为本项目独立编写。

旧客户端仍走原会话验证，云端受阻时返回升级提示；新客户端根据 challenge 的 `verification` 选择证书方案。账号、好友、房间数据库不迁移。Unbox 邮箱账号流程不变。

## 验证状态

本地 Node 33 项、macOS Rust 26 项通过，包括伪造签名、换身份、换挑战、过期、畸形输入、私钥不外传检查。测试用 RSA 私钥是随机生成的公开测试夹具，不是实际账号凭据，且不会通过生产 Mojang 信任根验证。

Cloudflare 运行时验证和用户真实账号显示好友码仍待完成；编译及模拟测试不能代替真实账号端到端验证。
