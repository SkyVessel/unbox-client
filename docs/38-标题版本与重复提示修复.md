# 标题版本与重复提示修复

日期：2026-10-18。此记录仅覆盖用户新增的两个标题界面问题，不代表本轮模组移植、建筑功能和联机优化全部完成。

## 改动

- `UnboxHomeScreen.GlassButton` 原来给所有按钮附加与标签相同的原版 Tooltip，鼠标悬停或键盘选中时会另外绘制一个黑色提示框。现在文字按钮不再注册重复提示；纯图标按钮保留说明，多人游戏因账号限制而不可用时保留原因。按钮外观、高亮、键盘操作和朗读逻辑不变。
- 标题左下角版本号改为读取 `SharedConstants.getCurrentVersion().id()`，不再写死 26.1。Fabric 和 NeoForge 使用同一处实现。

## 验证与交付

- 六个原生模块分别编译：26.1、26.1.2、26.3 × Fabric / NeoForge。
- `HomeSmokeTest` 在实际游戏中检查文字按钮没有重复提示、图标说明保留、多人按钮提示与可用状态匹配、键盘选中正常；继续执行原有标题导航、返回、小窗口与 GUI 缩放检查。
- 六种组合均通过，每种 30 项检查；逐一查看选中 Multiplayer 的游戏截图，未再出现重复提示，左下角分别为正确的 26.1 / 26.1.2 / 26.3。
- 测试只使用隔离目录中的存档副本，标题测试不会进入世界。原始运行日志位于 `.cache/title-fixes/`，汇总与截图归档在 `design/validation/title-fixes-2026-10-18/`。
- 本地 macOS 调试应用为 `src-tauri/target/debug/bundle/macos/Unbox Client.app`。重新打包后，六个内嵌模块与构建产物逐一比对 SHA-256，并重新施加本地 ad-hoc 签名以通过 `codesign --verify --deep --strict`。
- 未发布 GitHub 更新，未进行 Windows 游戏实测。需保存退出游戏，并从本地新测试应用重新 Launch 才会加载修复。
