# 1.21.11 Fabric PvP 统一设置面板

日期：2026-11-14。用户要求所有模组卡片连接 Unbox 自己的设置面板，替换第 96 篇中的第三方设置页跳转方案。本轮为本地开发交付，不公开发布。

## 入口与操作

1.21.11 Fabric 的 16 个外部 PvP 模组卡片直接进入 `UnboxScreen`，使用现有两色主题、响应式尺寸、设置搜索、分类、滚动与即时页面过渡。Survival / PvP 重叠模块继续共用原来的后端，未复制配置。

- 开关、滑块、数值、枚举、颜色与透明度直接写入原模组配置；文字和小数输入使用 `Apply` 提交。
- 按键在 Unbox 页内录入，Esc 取消，Delete 清除；保留 Right Shift，检测已注册按键冲突。
- Crosshair Addons 的图标使用 Unbox 像素编辑器：左键绘制、右键擦除，支持颜色/透明度、前后帧、复制/删除帧、清空及分辨率调整。图标偏移、尺寸和动画速度在 Appearance 中设置。
- `Reset settings` 恢复适配器提供的上游默认值；外部设置不使用 Unbox 内置模块的撤销快照。
- JAR 启停仍显示 Loaded / Disabled / Restart required，重启后生效。没有配置的模块明确显示无额外选项，不能编造一组无效设置。

本轮替换的是 Unbox 卡片和设置导航。第三方模组自己注册的命令或原生设置快捷键未被全局拦截。Eating Animation Pack 是资源包，继续提供作者下载和资源包管理入口，不计入 16 个模组。

## 实际后端覆盖

| 模组 | 数据及保存方式 |
| --- | --- |
| Crosshair Addons、Shield Fixes | 读取 WalksyLib 已注册的 Config、Option 与默认值，调用 `saveAndNotify`；图标直接编辑原 PixelGridAnimation |
| Better Totem Counter | `Config.get()` 对象与 `save()` |
| AppleSkin | 游戏实际使用的 `ModConfig.INSTANCE` 与 `save()` |
| Combat Hitboxes | `Config.getInstance()` 与 `save()` |
| BactroMod | `Config.load()` 与 `Config.save(config)`，读取选项范围注解 |
| Shulker Box Tooltip | 先初始化 PluginManager 颜色注册，再读取 `savedConfig` 并调用 `ConfigurationHandler.saveToFile`；保留服务端同步配置关系 |
| ElytraPitch | AutoConfig 的真实 ConfigHolder 与 `save()` |
| Shield Cooldown HUD | `ShieldReturnConfig`；位置数值、按键与 Unbox 的灰色背景开关 |
| HitColor | YACL 实际 ConfigHandler 对象；颜色编辑保留 alpha，alpha 可单独调整 |
| Better Hitreg | `Settings` 的开关、数值、Style 颜色/透明度及保存与刷新；统计记录不作为用户设置 |
| Natural Motion Blur、TweakHands | 加载时写实际配置；默认关闭时按锁定版本字段编辑对应 JSON，保留其他键，临时文件写完后替换；无法解析的原文件保留并提示错误 |
| ElytraSwapper+、Look Behind | 原模组注册的按键与 JAR 启停 |
| Status Effect Timer | 作者没有额外配置，提供 JAR 启停及明确说明 |

Natural Motion Blur 的临时录制覆盖层状态不属于持久化选项，本轮未接入其会话控制。模组未加载时，只有默认关闭的 Motion Blur / TweakHands 提供离线配置适配；其余模块需先启用并重启才能读取原配置对象。

字段与 API 对应 `client-mod/pvp-lock-1.21.11-fabric.json` 中的版本。升级依赖时应重新核对字段类型、数值范围、默认值、保存副作用，不能只验证反射成功。适配器按模块懒初始化，不逐帧读取配置文件。保存错误在页脚显示。

## 源码范围与迁移约束

- `client-mod/src/1.21.11/fabric/java/PvpSettings.java`：真实配置适配器；`PvpIconScreen.java`：图标编辑；`PvpSettingsChecks.java`：显式测试开关下的验证。
- 同目录 `PvpModules.java`：卡片直接打开 Unbox 设置；`PvpModuleScreen.java` 仅保留资源包信息。
- `client-mod/src/26.3/java/UnboxScreen.java`：共用设置控件，外部配置写入通过版本专属桥接；`PvpSettings.java` stub 保证其他加载器不依赖 Fabric 的外部模组。
- `scripts/prepare-version-sources.py`：只为 1.21.11 Fabric 注入实际配置桥接。修正原生 Viewmodel / Daytime 声明的版本范围，26.3 不添加这两个 PvP 模块。
- `scripts/solid-backport.py`：包含共用 stub；`PanelStyle` / `SolidGeometry` 复用现有矢量图标，修复部分详情缺失图标。

后续版本移植应保留直接使用自有设置页的原则，逐项适配目标版本的真实后端；不能只放一个同名面板、写入第二份未被原模组读取的配置，或再退回作者设置页跳转。

原生构建通过：1.21.11 Fabric / NeoForge、26.3 Fabric / NeoForge。本地调试启动器打包通过。没有修改 26.1、26.1.2、1.20.1 的设置实现。

| 检查 | 结果 |
| --- | --- |
| 默认 PvP 安装组合 | 66 项通过 |
| 单独隔离目录中启用 Motion Blur / TweakHands | 66 项通过 |
| 26.3 Fabric 共享 UI 回归 | 64 项通过 |
| 源码生成版本范围测试 | 5 项通过，包含非 1.21.11 Fabric 不注入 PvP 配置和原生功能的断言 |

两组 1.21.11 检查遍历 16 个模块，验证页面类型、设置可用性；有开关的模块用原生鼠标事件修改并检查上游配置文件字节发生改变，再还原。另覆盖代表性数值、颜色、下拉、按键及图标写入；按键页验证 Esc 取消和重新绑定。对无配置模块仅验证页面和可用操作，不声称其进行了配置文件写入。

证据位于 `research/verification/pvp-settings-1.21.11/`：两组 66 项报告、26.3 报告、按模块保存检查摘要及设置/图标编辑截图。检查使用独立离线身份，没有进入世界、操作视角、验证战斗效果或线上服务；离线授权和可选兼容目标警告不能描述为线上登录通过。

复现默认菜单检查：

```sh
./client-mod/gradlew -p client-mod -Pminecraft=1.21.11 build
python3 scripts/test-backport-fabric.py 1.21.11 --java /absolute/path/to/java21 --smoke portUi --pvp --reset-settings
python3 scripts/test-solid-ui.py --name own-settings-26 --checks-only
python3 tests/test_backport_sources.py
```

`--reset-settings` 仅用于脚本的隔离测试目录。用户手动测试用 `--interactive`，不传自动检查、自动进入世界或重置设置参数。不要覆盖正在运行的手动实例；旧实例退出后再安装新 JAR。
