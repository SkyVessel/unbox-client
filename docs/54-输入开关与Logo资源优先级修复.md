# 输入开关与 Logo 资源优先级修复

2026-10-19，准备 0.2.15 测试更新。发布状态在完成平台构建、游戏回归和公开附件核验后补充。

## Effortless Building

旧逻辑每五个 tick 检查权限并关闭已打开的建造界面，但上游每个 tick 都会读取物理按键，按住径向菜单键会再次打开，造成闪屏。

- 在上游 `KeyBindings.isKeyDown` 入口检查建造权限；关闭功能或非创造模式时直接返回 false，阻止菜单创建。
- 在 `KeyMapping.consumeClick` 入口仅拦截 `key.effortlessbuilding.*`，清空禁止期间的设置/撤销/重做点击。
- 原有取消建造序列和关闭界面只在“允许 → 禁止”转换时清理一次；保留服务器侧建造权限检查。
- 回归直接调用原生加载器 tick 回调，在 Unbox 清理运行之前检查没有创建 Screen；持续输入 20 次，并验证重新启用后的真实设置界面与无积压按键。

## Mouse Tweaks

Mouse Tweaks 自身事件门禁有效，但 Inventory Profiles Next 的 `MiscHandler.swipeMoving` 仍能接收 Shift + 鼠标拖动。过去仅仲裁滚轮，且 Mouse Tweaks 关闭时会启用 IPN 的滚轮处理，导致两个功能开关含义不一致。

- 由 Mouse Tweaks 独占增强拖动与滚轮，禁用 IPN 的重复处理入口及对应配置。Inventory Sort 继续负责排序、补充、锁槽等原有功能。
- 移除 Inventory Sort 中重复的滚轮选项，鼠标增强选项统一在 Mouse Tweaks 设置内。
- 不修改原版容器拖拽。回归覆盖 Mouse Tweaks 左右键点击/拖动/释放、配置重载、重新启用，以及 Inventory Sort 开启而 Mouse Tweaks 关闭的情况。
- 已在 26.3 Fabric 的真实容器复现修复前拖动移动石头；修复后同一用例通过。测试设定真实容器、按键集合与划过格子的轨迹，先确认原生点击能够搬动物品且上游几何路径命中目标，避免空操作误报通过。

## Logo 与材质包

保留独立的 `unbox:name_badge` 字体 ID 和 0.2.14 的 128px 字体纹理。添加仅包含七个品牌资源的内置最高优先级资源层，保护字形定义及基础/皇冠/现金图像，不覆盖世界材质、原版字体或文字着色器。

冲突夹具使用顶层材质包覆盖同名 Unbox 字体和纹理，并覆盖核心文字着色器触发 ImmediatelyFast 字体图集兼容回退；回归检查七个资源实际读取的字节和基础/皇冠/现金字形烘焙。

## 验证状态

六套原生模块已编译并通过 bundle 检查；26.3 Fabric 输入回归 58 项通过。其余游戏目标、材质包夹具、两平台打包及 updater 发布核验进行中。

所有实际游戏测试运行于 macOS 隔离存档；没有 Windows 游戏实玩证据，也未取得用户的具体材质包。保护品牌资源不能保证任意第三方自定义文字着色器的所有绘制效果。未修改生产 Worker、账号权限或资产设计。
