# 异地联机玩家测试清单

适用：已发布的 **0.2.11**。先确认双方都已通过启动器更新，再进行以下测试。0.2.10 及更早版本不包含本轮账号迁移与联机调整。

## 1. 准备

- 两台电脑分别使用不同网络，例如家庭宽带与另一处宽带，或一台连手机热点。两台电脑连同一路由器不算异地。
- 双方确认公网出口不同即可，无需向开发者提交完整公网 IP。
- 记录：系统、启动器版本、Minecraft 版本、Fabric／NeoForge、网络类型和大致地区。
- 用新建测试世界，避免拿重要存档试验。至少一人有可登录的正版账号，另一人创建本地账号。
- 双方启动器保持运行；通过客户端 Friends 添加好友、接受请求和发送世界邀请。不要改用直接连接中继地址，私密房间需要邀请凭证。
- 第一轮保持相同 Minecraft 版本和加载器，先排除版本差异。

## 2. 必测组合

每种组合分别执行下一节步骤。

| 房主 | 访客 | 检查重点 |
|---|---|---|
| 正版 | 本地 | 本地玩家能通过邀请进入，昵称正确 |
| 本地 | 正版 | 本地账号可以正常开房，正版可加入 |
| 本地 | 本地 | 无邮箱、无正版登录的私密联机正常 |
| 正版 | 正版 | 原有正版联机没有退化 |

至少在 26.3 完成四种组合；随后在 26.1、26.1.2 各完成一次联机。Fabric 与 NeoForge 各覆盖一次；跨加载器切换单独放在环境同步测试。

## 3. 一次完整联机

1. 房主进入新世界，通过 Friends 邀请访客。
2. 访客在启动器接受邀请，记录从点击加入到能够移动的耗时。
3. 检查双方昵称、皮肤、所在世界；本地改名后仍应保持自己的背包、位置和身份，不应变成房主。
4. 连续游玩 10 分钟：移动、挖掘、放置、开箱、捡物品、互相观察。记录瞬移、交互延迟、掉线和物品回弹。
5. 有条件时让两位玩家使用相同昵称再次加入；两人的背包与权限必须独立。
6. 访客退出到标题界面，再用同一个有效邀请加入；环境未变时不应重复下载玩法模组或无故重启。
7. 房主停止共享；访客不能继续通过该房间正常加入。房主重新邀请后应能恢复。

通过标准：四种身份组合都可进入正确世界，基本操作连续正常，无法靠同名取得房主权限。具体公网网络是否顺畅，以实际记录为准。

## 4. 环境同步与加入体验

- **游戏未启动**：接受邀请后应准备正确的版本和加载器，自动进入好友世界。
- **游戏已启动且环境相同**：不应无故先关闭当前游戏。若正在自己的世界，观察退出／保存提示是否清楚。
- **缺少房主的玩法模组**：应显示准备进度，下载完成后必要时重启，随后自动加入；失败应能理解原因并重试。
- **房主启用资源包／光影**：检查同步结果和启用顺序，记录是否有错误覆盖个人按键、HUD、音量等。
- **重复加入**：相同文件不应重复下载；退出好友环境后自己的 Profile 和个人文件仍在。
- **版本或加载器不同**：应选用匹配的好友环境，不应把 Fabric JAR 放入 NeoForge。分别记录自动切换与必要重启的表现。

这里不要求自动同步任意整合包的全部 config／脚本。遇到这类文件差异，请单独记录文件类型和现象。

## 5. 中断、网络与延迟

- 访客断网约 20 秒，再恢复网络。观察错误提示、重新邀请／加入能否恢复，不要求游戏无缝恢复连接。
- 房主正常退出游戏，再重新打开世界邀请。不能卡在永久 Joining／Preparing。
- 游戏和启动器分别重启一次，确认本地昵称、皮肤库、世界背包仍然保存。
- 记录每轮加入耗时；若游戏可显示数字 Ping，每隔 30 秒记一次，共至少 10 次。仅有信号格时记录格数，不换算成毫秒。
- 分开记录 FPS 与网络延迟；“画面卡”和“开箱／放块晚响应”分别说明。

先记录实际 Ping、变化范围和交互表现，不预设所有网络都能达到同一个延迟数字。频繁跳变、持续物品回弹或掉线都应列为失败现象。

## 6. 本地账号边界

- 断网仍可启动支持的 Fabric／NeoForge 单人世界、修改本地昵称和管理皮肤。
- 本地账号不能通过普通多人服务器入口／直接连接进入公开服务器；应有清楚提示。
- 通过 Friends 私密邀请仍可联机；现有免费 Client Mods 不应因为没有 VIP/MVP 而被锁定。
- 本地账号没有官方资产或 VIP/MVP。皮肤页显示圈 N；正版账号不应出现本地改名按钮。
- 本地账号目前要求 Fabric／NeoForge，以执行私密连接限制；Vanilla Profile 应在下载前给出提示。

## 7. 失败时给我的资料

提供：测试组合、双方系统／版本／加载器、发生时间、操作步骤、错误提示截图，以及能否稳定重现。

日志位置优先使用启动器的打开日志／数据文件夹入口。主要文件是出问题 Profile 下的 `logs/latest.log`，同步问题附 `logs/environment-sync.json`（存在时）。

**不要发送** Microsoft 凭证、系统钥匙串、`unbox-social-view.json`、邀请秘钥、账号数据库、完整数据目录或管理后台令牌。发送日志前遮盖私人聊天、连接地址和个人路径。
