# 0.2.7 测试更新发布

2026-10-13，用户授权推送本轮修复并发布供客户端更新的 Release。已发布 [v0.2.7](https://github.com/SkyVessel/unbox-client/releases/tag/v0.2.7)，GitHub latest 指向此版本。源码提交 `103babf9c0ae0c1d332cf85ee3cde581c9b0fd01` 已推送 main。

## 发布内容

包含文档 25 的 26.1.2 原生 Fabric/NeoForge 支持、共享玩法 JAR/ZIP 材质包/光影包及启用选择、未启动游戏时接受邀请、紧凑邀请弹窗、游戏内好友管理、文件/Profile 可撤销删除、玩家名字徽章。

- macOS ARM64：`Unbox.Client_0.2.7_aarch64.app.tar.gz`，21,837,463 字节。
- Windows x64：`Unbox.Client_0.2.7_windows-x64-setup.exe`，12,624,099 字节。
- 两平台 `.sig`、`latest.json`、`SHA256SUMS.txt` 和 26.1/26.1.2 × Fabric/NeoForge 四份 JAR。
- 沿用原 updater 公钥。私钥仅在本机用于签名，未发送 GitHub/CI，未更换已有更新信任链。
- 延续测试构建模式，无 Apple 公证或 Windows 发布者证书；没有 Intel Mac/Linux 包。
