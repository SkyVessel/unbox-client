# 生存客户端与游戏内 UI 开发验收

2026-10-14。用户已明确授权将认可的悬浮 UI 与本轮功能开发到实际客户端。本轮暂不实现新的披风功能、建筑模组；现有 OptiFine 披风显示保留。尚未发布新的 GitHub Release。

## 已确认的实现范围

- 保留原有模块图标；为新增模块添加图标，Nickname 使用身份卡图标。
- 游戏内 Mods 使用正方形悬浮卡片，无外围底板；底部红/绿状态条只显示居中文字。
- Right Shift 首屏皮肤预览，头跟随鼠标、水平拖动旋转；皮肤库与游戏侧切换闭环。
- HUD 改用 Minecraft 像素字体；拖动白色细描边，无 Drag to move 标签。
- 主菜单 Friends 保留原背景，全屏 Unbox 标题不叠在好友界面。
- 分数板外观、仅自己可见的昵称、平滑上坡、自由相机、死亡物品保留及房主状态同步。
- 专用服务器中自动限制不能保证兼容的玩法功能；保存个人开关偏好，允许明确识别的 LAN 与 Unbox 好友房间。墓碑由集成服务器房主决定。
- 同机跨版本共用世界与材质资源库，个人玩法环境与好友托管环境分开；显示真实内容来源。

## 验证记录

- 首轮 Fabric 26.1 实际游戏 `survival-v4-ui-first`：134 项 UI/既有功能回归通过。包括真实卡片交互、颜色取消与保存、HUD 拖动/缩放、设置与收藏持久化、原生粒子 opacity、地图权限、好友通知；并逐项打开新模块设置页面。
- 本次测试使用历史测试世界的独立副本，没有打开用户生产世界。
- 截图：`.cache/benchmarks/survival-v4-ui-first/screenshots/`。此轮不代表新增墓碑/背包整理/动态光源的行为已通过，后续记录另列。

## 集成与许可

- 既有 Minimap/粒子/准星保留当前原生实现。JourneyMap/Xaero 二次分发权限尚未取得，不随客户端打包。准星增加逐笔撤销，保留分享码、预设和颜色预览。
- 动态光源集成 MIT 授权的 [Wick](https://github.com/comedy01/Wick)，按加载器锁定官方版本和哈希；原 JAR 自带许可证，另保留 `notices/wick/LICENSE`。Fabric/NeoForge 的实际运行记录见后文。
- 新图标沿用既有 ISC Lucide 图标体系，仅生成新增文件；旧图标纹理不重写。



## 使用方式与准确边界

| 功能 | 使用入口与行为 | 专用服务器 / 房主要求 |
|---|---|---|
| 外观、HUD、准星、粒子、计分板、昵称、物品掉落视觉 | Right Shift → Mods；Nickname 只改自己的名牌与玩家列表显示 | 本地渲染，无需服务器安装 |
| 动态光源 | Mods → Dynamic Lights；启动器按加载器自动准备 Wick | 本地渲染，无需房主安装；本轮没有开启光影包验证 |
| 平滑上坡 | Mods → Smooth Step，跨一格台阶 | 专用服务器禁用；单人、原生发现的 LAN、已验证好友房间可用 |
| 自由相机 | Mods → Freecam 后按 F6；WASD、空格、Shift，冲刺加速 | 同上；退出、切换世界、死亡、关闭模块时恢复 |
| 背包整理 | 启用 Inventory 后物品栏 Sort | 同上；只整理主背包 27 格，保留快捷栏、盔甲与副手，不整理箱子 |
| 墓碑 | 房主启用 Gravestones，访客显示房主开关状态 | 集成服务器房主决定；原版背包/盔甲/副手，保留 keepInventory 与消失诅咒规则 |
| 皮肤 | 启动器保存多个 PNG，游戏内 Change skin 切换 | Microsoft 账号调用官方接口；Unbox/本地账号的替换仅本机可见 |

- 皮肤预览使用原版人物渲染，头跟随鼠标，水平拖动持续旋转。暂不新增披风库、披风切换或建筑模组。
- 掉落物为轻量原生视觉：落地平躺并停止浮动旋转，空中翻滚；不是完整物理模组，也不把所有二维物品自动变成体积模型。
- 本轮保留原生地图，没有把未获分发许可的 JourneyMap/Xaero 包装成已集成。
- 共用库只共享世界和材质资源，普通玩法 JAR 继续按版本/加载器分开；好友托管环境独立。原目录保留为 `.unbox-profile-copy`，同名世界不覆盖，同名不同内容的材质包保留扩展名并重命名。
- 世界库检查依据是“上次经 Unbox 准备的环境”，不是读取存档真实版本。首次/升级准备会要求独立备份；游戏内直接选世界仍走 Minecraft 原有流程，不声称有全局防降级保护。
- 内容列表按真实共享清单与文件哈希区分 From host / Yours，不仅依靠文件名。
- Windows 尚未实玩或验证目录联接；本次为 macOS 本地开发交付，不发布 GitHub 更新。

## 最终验证（2026-10-14）

- Rust：50/50 通过，包括皮肤索引更新/删除/异步提交、共享库迁移/回滚/备份、内容来源哈希识别及原有账号/联机测试。
- Node/浏览器：40 项测试中，39 项首轮通过；皮肤提示文案断言更新后，单项复跑通过。不是对真实 Microsoft 账号做皮肤上传，官方接口序列化使用本地 mock。
- Fabric 26.1：`survival-v4-fabric261-final` 实际游戏 30 项通过。包含真实 Wick 手持火把光源、关灯后源清理、上坡属性开关、F6 相机/身体输入隔离、皮肤文件与 UUID/损坏校验，以及悬浮界面交互。
- NeoForge 26.1.2：`survival-v4-neo2612-freecamfix2` 同一组 30 项通过。修复了 Freecam 只清按键而遗漏计算后移动向量导致身体移动的问题；实测镜头位移约 7.185 格、身体位移 0。
- Fabric 26.1.2：`survival-newmods-1014-final3` 生存测试 5 组通过。真实物品栏点击协议排序 27 格，并核对物品组件和数量；墓碑满背包保护、关闭后回收、keepInventory、虚空落点；真实死亡→复活后到死亡维度/坐标核对墓碑物品 UUID 与总数。
- 墓碑的完整退出→重载恢复、两台电脑房主切换状态同步、第三方饰品槽、开启光影后的 Wick 兼容性，本轮没有实测，不能把编译或同机测试作为这些场景的证据。

- NeoForge 26.1：`survival-v4-neo261-final` 实际游戏 30 项通过。
- NeoForge 26.1.2：`survival-v4-neo2612-final` 生存测试同样 5 组通过，含真实背包点击协议与死亡/复活物品守恒。
- 四个版本/加载器组合均已独立编译，无运行时 Fabric 转换。最终应用资源会逐个比对 JAR，避免打包旧模块。
- 视觉复查发现原版 `GuiGraphicsExtractor.entity` 不应用普通控件矩阵，已修正玩家预览的绝对坐标与大小换算，保证大号 GUI 缩放时仍处于正确位置。视觉截图测试关闭测试环境中的 Dynamic FPS 后台限帧，避免截到尚未完成的进场首帧；生产包仍保留 Dynamic FPS。

- 最终玩家预览缩放修复后，Fabric 26.1.2 `survival-v4-scale-final` 30 项通过；人工检查 GUI scale 2/6 的菜单和正方形卡片截图，人物与按钮位置正确。

本地调试交付：`src-tauri/target/debug/bundle/macos/Unbox Client.app`，打包成功且四份最终 JAR 与源资源逐字节一致，SHA-256 记录在 `.cache/survival-v4-bundle-sha256.json`。未替换系统 Applications 下的应用，未上传 Release。
