# UI 参考图与壁纸选集

查阅日期：2026-10-05。状态：用户已完成选图；选择与后续规范见 [视觉方向与设计规范](./05-视觉方向与设计规范.md)。

已选 UI：L1、L2、F1、F2、F3、F4。已选背景：W1、W3、W4、W6、W8。下文推荐语保留为选图时的研究记录，不代表用户选择。

## 已确定的方向

- 原版 Feather + Lunar；明确排除 Dawn。
- 一个连续面板、少分割线、无边框图标与磨砂玻璃；操作含义清晰优先。
- 背景集中于 Minecraft 官方视觉与光影游戏风景。此处把“官方 UI”先按官方背景与美术方向整理，未将其解释为照搬原版像素按钮。
- 下列图片是风格参考，不等于已选择或可随客户端分发的素材。

## 如何挑选

打开本地选图板 http://127.0.0.1:8765/ ，点击图片放大，点击“喜欢这张”，复制选择发回聊天。也可以直接回复编号。

可分别选择：整体结构、玻璃层次、背景气氛。例如：“F1 的磨砂，但不要格子；W4 的暖色森林”。不必选择完整照抄的客户端。

## 建议先看的组合（未替用户决定）

- **F1 + F2**：原版 Feather 的玻璃面板与轻量浮层。借鉴场景感，进一步减少网格和边界。
- **L2**：集中注意力的入口层级；只参考少量选择与主动作。
- **W3 / W4 / W6**：樱花、森林、冰峰，可以比较明亮柔和、温暖沉静、冷暖对照。
- **W7 / W8**：Minecraft 官方美术的温暖与探索感。
- **W1 / W2**：有可追溯订阅数据的社区光影场景。

## 选图后再确定

记录用户选择与排除项，再定义：背景构图与裁切、颜色与对比、字体层级、留白与密度、面板透明度/模糊、图标与按钮、状态反馈、页面切换与背景过渡、减少动态效果和低性能降级。

目前只记录可研究的原则：让背景形成世界感；让留白形成结构；让主动作清楚；让玻璃帮助阅读。具体 token 数值和最终页面布局尚未批准。

## 素材与预览说明

- UI 截图来源于 Lunar / Feather 官网；Feather 官网的品牌迁移不改变本项目只参考旧版的约束。
- W7/W8 是官网方形缩略预览，不能据此确定最终宽屏裁切；选中后应先检查来源页提供的原始壁纸。
- W1/W2 原作品是动态壁纸，本轮仅展示静态预览。采用动画背景需要另外评估资源消耗；当前不默认开启。
- 素材仅用于审美研究；进入产品制作时再落实合适授权、原创或自行拍摄的替代资产。
- 预览使用远程图片，需联网；完整编号、来源和说明保存在 `design/references/references.json`。
