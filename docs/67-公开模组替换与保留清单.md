# 公开模组替换与保留清单

日期：2026-10-23。分支：`codex/public-mod-replacements`。这轮不上传自制模组到 Modrinth、不重绘图标、不发布 GitHub 更新。

## 结论与选择依据

本轮新增替换 **1 项：Freecam → MinecraftFreecam/Freecam 1.5.1（MIT）**。不是把当前所有卡片都算作自制：其中大量功能原本已经下载公开模组或使用带源代码的原生移植版本。

“可直接替换”在本轮指：覆盖 26.1、26.1.2、26.3 的 Fabric / NeoForge，保留现有功能的主要交互，能接入真正的开关，不丢失存档数据。可以增加薄的设置和权限适配，不为了统一来源而重新实现上游缺失的大量功能。未入选表示目前不符合这组要求，并非永远无法替换。

## 本轮实际替换

[Freecam 项目](https://modrinth.com/mod/freecam) · [上游源码](https://github.com/MinecraftFreecam/Freecam)

- 六种环境固定到上游 1.5.1 的对应 JAR；保持原 JAR 不变，启动器从公开下载链接获取并校验 SHA-1 / SHA-512。
- 移除自制 SpectatorCamera 以及旧输入、转向、人物渲染、手部、交互拦截五个 Mixin。相机实体、位移、惯性、人物本体、交互及退出清理由上游负责。
- Unbox 保留卡片开关、可信私密房间限制和原生设置入口。`postTick` 快捷键处理和 `toggle` / `toggleTripod` 在创建相机前被拒绝，不采用先开启再关闭；关闭时不会通过三脚架组合键吞掉数字快捷栏输入。
- Right Shift 的快捷键直接编辑上游 KeyMapping；已有 `freecam.key` 继续迁移。没有第二个 Unbox Freecam 快捷键。新用户未保存旧键时使用上游默认键 F4。
- 原生设置页提供移动速度、飞行方式、碰撞、人物显示、受伤退出、交互、通知等选项；保存由上游管理，Unbox 不逐帧覆盖这些设置。右 Shift 的重置按钮明确为 `Reset keybind`。
- 新建配置默认使用上游 CREATIVE 惯性飞行，基础水平 / 垂直速度 0.5；已有 `freecam.json` / `freecam.json5` 保留。原有滚轮临时调速通过上游速度返回值的倍率实现，不再自写飞行动力学、不每次滚轮写盘、不切换本体物品栏；每次进入重置倍率。
- 标记为客户端托管依赖，阻止通过 Discover / 文件导入安装重复副本；好友环境清单排除这类个人客户端引擎。
- 第三方声明收录上游 MIT 许可证。修正声明生成器对 `freecam.LICENSE` 这类后缀文件名的识别。

## 暂时保留的自制部分

| 自制功能 | 核查候选 | 保留的具体原因 |
|---|---|---|
| 小地图 / 大地图 | Xaero's Minimap + World Map、JourneyMap | Xaero 当前正式发行列表没有精确覆盖 NeoForge 26.1；JourneyMap 没有精确覆盖 26.1 的两种加载器。现有队友最后死亡标记、头像、双击传送和地图缓存也没有一对一迁移方案。不能用 26.1.2 标签强行宣称支持 26.1。 |
| Gravestones | Gravestones、You're in Grave Danger | 查得版本未覆盖六种环境；既有墓碑物品持久化和破坏取物规则需要数据迁移，直接删掉自制实现会危及已有死亡物品。 |
| Zoom | Zoomify、Ok Zoomer、Simple Zoom、Zoomly、Logical Zoom、Scope | Zoomify / Ok Zoomer 有覆盖版本，但没有对应的完整模块关闭 API，且额外接管望远镜、灵敏度等路径。直接开关键不足以还原所有行为。Simple Zoom 缺少现有 Hold/Toggle、可配平滑过渡等选项；把这些重新写一遍并不构成直接替换。其余候选存在功能或精确版本缺口。保留当前实现，不声称 Zoomify 缺少游戏版本。 |
| Crosshair | Custom Crosshair Mod、CustomCrosshair | 前者没有查得 NeoForge 26.1 的精确正式构建；后者没有目标版本构建。自制像素画布、设计分享和预设继续保留。 |
| Armor Status | uku's Armor HUD、Simple Armor HUD | uku 支持六种环境，但与现有按装备槽显示、主副手物品、名称、背景 / 比例、拖动布局及耐久组合格式并不等价；Simple Armor HUD 缺少 NeoForge 和部分版本。保留原有完整 HUD。 |
| FPS / CPS / Keystrokes / Coordinates / Latency | BetterF3、CustomHUD、MiniHUD、Simple HUD Enhanced、FPS Display、Keystrokes | BetterF3 重做 F3 调试界面，不能直接代替这组常驻可拖动 HUD。其余候选未覆盖完整版本 / 加载器组合。 |
| Auto Sprint | ToggleSprint、Better Sprint、Simple Toggle Sprint 及 26.3 NeoForge 搜索 | 未确认能覆盖六种环境且等价自动前进疾跑的公开构建。原版 Toggle Sprint 仍需要先按疾跑，和当前 Auto Sprint 不等价。 |
| Chat | Chat Patches | 无 NeoForge 构建；现有背景、透明度、行高等是与原版选项连接的小型模块。 |
| Scoreboard | Scoreboard Overhaul | 无 NeoForge 构建，无法统一替换当前侧栏颜色 / 透明度设置。 |
| OptiFine Cape | Capes | 查得 Capes 的目标版本为 Fabric，缺少 NeoForge；保留当前正版披风获取 / 渲染。其他自定义披风服务不能等价替代 OptiFine 资产来源。 |
| Happy Ghast | Speedy Ghasts，以及相关飞行速度候选 | 未确认完整版本覆盖且包含当前房主速度规则、召唤、15 格范围与等待恢复行为的直接替代品。 |
| Nickname / 名牌 Logo | 保留 Unbox 身份与外观模块 | 本地改名、正版 / 本地身份、客户端身份徽标和官方资产规则属于 Unbox 业务，不替换成通用改名模组。 |
| NeoForge Freelook | Freelook、Perspective Mod Redux 等 | 当前使用的 Fabric Freelook 没有 NeoForge 发布；候选未覆盖六种环境。保留现有加载器适配。 |
| 性能测试器、联机和客户端 UI | 保留 Unbox 模块 | 需要统计 Unbox 功能自身耗时，或处理账号、好友、资产、Profile 和同步协议，不属于通用显示模组可直接替代的功能。 |

候选的项目来源、许可证、逐环境版本 ID 已保存于 `research/verification/2026-10-23-public-replacements/candidate-matrix.json`。这是查阅当日的正式发布快照；不存在某个精确构建的结论仅针对这次查到的版本列表。

## 验证

- 六套原生模块编译通过；没有旧 `SpectatorCamera` 或五个旧 Freecam Mixin 残留，两个上游适配 Mixin 均进入实际 JAR。
- macOS ARM64 上，26.1 / 26.1.2 / 26.3 × Fabric / NeoForge 均在隔离存档中完成 **32 项检查**，包括真实上游相机、旧快捷键迁移、关闭入口不创建相机、不吞数字键、开启后不重放旧按键、四方向移动、鼠标不转动本体、滚轮调速、物品栏不切换、关闭恢复、原生设置页往返和共享清单扫描。
- 所有游戏测试启用 SilentGameAgent，日志确认隐藏窗口和禁用焦点；没有启动用户当前 Profile 或修改其存档。
- 4 项启动 / 已托管文件迁移测试、6 项共享环境测试、1 项重复托管模组安装阻止测试通过。目录 / 哈希 / MIT 许可证核对、客户端设置目录同步测试和前端生产构建通过。
- 原生 JAR 的 SHA-256 与逐项结果见 `research/verification/2026-10-23-public-replacements/runtime-results.json`。
- 这是本机六环境功能验证，未描述成 Windows 实玩、异地联机或 FPS 对比。尚未打包或发布新的 macOS / Windows 启动器更新；当前已安装的发布版不因此自动变化。
