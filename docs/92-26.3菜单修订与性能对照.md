# 26.3 菜单修订与性能对照

日期：2026-11-12。本轮针对 26.3 Fabric / NeoForge，仅本地调试交付。

## 用户要求与实现

- 主菜单使用游戏原版 Panorama，不调用模糊步骤；删除纯色主底板遮挡。
- 移除各纯色菜单左下角 Reduce motion 入口；保留已保存偏好及原版 Screen Effects 关闭时的减动画行为。
- 主菜单中央弧线改为两端吸附的 White / Red、Gray / Yellow 主题切换。快捷菜单透明度弧线、Mods 左侧透明度尺及右上主题弧线保留各自功能。
- Mods 列表外层底板归入实心前景，不随背景透明度变化。
- 模块设置页使用列表页的相同外框位置和可用尺寸，GUI Scale 改变时重新布局内容。
- 布局与矢量轮廓尺寸按状态缓存，跳过不可见控件绘制，主菜单不再生成和上传无用的整屏背景纹理；字体首次解析移到绘制工作线程。

## 测量方法

用户本轮明确允许使用独立存档、固定视角测试；仍不操作视角、不读取或修改用户存档。

使用 `scripts/benchmark-solid-ui.py` 生成固定种子 20261112 的独立原版地形存档，后续各次运行复制同一模板。测试类仅注入 `.cache/ui-performance/` 下的临时 JAR，交付 JAR 不含该测试替换类。

- 修改前构建：`.cache/ui-performance/before/`，分别保留 Fabric / NeoForge JAR。
- 每个场景预热 8 秒、采集 15 秒；title、world、quick、mods、mods-scroll、settings 分开统计。
- 1280×720 启动请求，实际 framebuffer 写入报告；GUI Scale 2，渲染距离 12、模拟距离 8、关闭垂直同步、FPS 设置 260（游戏的 Unlimited 档）、4 GiB 堆。
- 两侧同样去掉仅用于后台限速的 Dynamic FPS，记录窗口焦点；不降低画质、不修改鼠标滤波。
- 启动时间为 JVM 启动至主菜单纹理可用，世界时间为打开同一存档至玩家和画面可用，不包含下载或启动器界面耗时。
- 此轮“之前版本”特指本次修改前的 26.3 构建；不是跨 Minecraft 版本比较。

## 公开优化模组核实

原有 Sodium、Lithium、FerriteCore、ImmediatelyFast、Entity Culling 保留。

- [ModernFix-mVUS](https://modrinth.com/mod/modernfix-mvus)：公开 26.3 Fabric / NeoForge release；先在隔离测试配置比较。
- [C2ME Fabric](https://modrinth.com/mod/c2me-fabric) / [NeoForge](https://modrinth.com/mod/c2me-neoforge)：对应版本为 alpha，先单独评估区块加载兼容性与收益。
- [Faster Random](https://modrinth.com/mod/faster-random)：作者已归档且只建议既有该模组世界使用，不加入。

原始发行元数据、JAR 校验值、测试结果在验证目录记录；是否加入交付以最终结果为准。

首轮校准发现 maxFps=1000 超出原版设置范围而回落至 120；该轮仅作 JFR 热点诊断，不计入最终 FPS 对比。后续写入原版有效值 260，并记录运行时有效限速，主菜单原版仍限 60 FPS。

## 追加滚动要求

用户追加要求将 Mods 改为有头有尾的平滑滚动。已取消绘制第二份循环列表；滚动目标与绘制偏移都限制在首尾之间，尾部不留一整行空白。筛选/分类变更重置位置，GUI Scale 变化时重新限制范围；输入命中使用同一偏移。性能对照滚动阶段改为在有效范围内往返，避免新版到达末尾后静止而使比较失真。

## 当前验证结果与用户选择

- Fabric / NeoForge 各通过 34 项原生菜单检查，包含主题弧线两端吸附、背景透明度保持、设置页四个外框坐标在 Auto/2/1 下对齐、首尾平滑滚动、点击位置与分类过渡。
- 367 项矢量透明度/Logo/几何检查、318 项响应式布局检查、5 项版本源码隔离检查通过。
- 26.3 两种原生构建及 macOS 调试应用通过；应用中六个客户端 JAR 与资源目录一致。
- 原生截图与构建日志：`research/verification/solid-ui-26.3/panorama-performance/`。

性能采样期间发现另一个原有 Minecraft 进程同时运行。用户选择“暂时保留游戏，只做功能与兼容性检查”，因此停止正式 FPS / 启动 / 世界加载速度比较；已有帧数与时间只作诊断，不提供提升百分比，不证明新版在所有场景更快。

新增地图优化只在 26.3 覆盖层内：同一区块内的北/西地形高度直接复用已取得的区块，仅越界时另查；非草地、树叶、水等不需要生物群系着色的方块不再读取生物群系。固定存档同一 32×32 区域优化前后 SHA-256 均为 `fa77819201372cf443c5ba126697d6faa573e2c44cd17182176f85c9a4170783`。此检查验证取色结果，不能代替玩家视角体验或全场景性能验证。

测试配置使用原生客户端和现有 performance-lock 中的性能依赖，不等于完整生存整合包、远程多人、其他平台或其他 Minecraft 版本实测。测试驱动使用虚拟账号，Realms 的预期 401 不当作业务账号验证。

四组证据及下载 JAR 哈希保存在 `research/verification/solid-ui-26.3/panorama-performance/compatibility/`。报告中的 `compatibilityOnly: true` 表明短时运行只验证上述流程；其中帧数和时间不用于收益比较。这些模组仍只存在于隔离测试目录，未加入默认依赖、用户配置或交付应用；没有据此宣称启动、区块加载或 FPS 已提升。候选间组合、长时间世界生成和完整整合包仍未验证。

所有本轮测试进程已退出，用户原有游戏保持运行。最终交付为 `src-tauri/target/debug/bundle/macos/Unbox Client.app`，六个内嵌客户端 JAR 校验一致，未包含临时固定视角测试替换类。
