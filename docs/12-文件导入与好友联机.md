## 使用流程

- Home → Mods / Packs / Shaders：把 `.jar` / `.zip` 文件拖到列表。列表每行两项并读取包图标。右上无边框、无文字 `+` 打开当前 Profile 对应文件夹。
- 导入不覆盖同名文件，混合批次逐项报告失败。运行中的 Profile 不接受导入；启动器管理的客户端模块不能通过此入口替换。不保证任意第三方模组支持 26.1 或兼容当前加载器。
- Friends → `+` → 填写对方 12 位 friend code → 对方 Accept。自己的 code 可点击复制。支持取消请求、移除好友、在线状态、头像和邀请。
- 两人使用正版账号，启动 Unbox Fabric 26.1；房主进入单人世界。Right Shift 快捷菜单右侧显示无边框好友列表，点击 Invite。启动器内同样可以 Invite。
- 客人点击 Join：先检查私网地址是否同子网，再进行 UDP 随机值往返探测，成功后直接连接房主游戏端口。不能用公网 IP 相同推断局域网相同。
- LAN 检测失败才向房主请求启动 e4mc。得到 relay 地址后进入正常 Minecraft 连接流程。世界邀请 5 分钟过期；失败显示状态并允许房主 Retry relay。
- Stop sharing 关闭 relay 和 LAN 探测、撤销访客 UUID 并断开访客；已有 LAN listener 在世界退出时关闭，停止共享期间不接受访客。再次开房需要重新进入世界。
- 邀请不自动同步玩法 Mods，本轮没有把环境同步冒称为完成；朋友仍须使用兼容的游戏内容。

## 身份及本地存储

好友服务只保存独立社交身份、散列后的社交凭证、公开玩家信息、好友关系和短期房间元数据。社交凭证在 macOS Keychain。Cloudflare 不接收 Microsoft/Minecraft access token。

第一次将正版账号注册为社交身份时，Worker 发放短期 challenge，启动器直接向 Mojang `join` 提交自己的会话，Worker 通过 `hasJoined` 验证 UUID。只有双方接受好友请求后才能发邀请；只有收件人能请求 relay。

游戏目录里的 `unbox-social-*.json` 和 `unbox-world.json` 是启动器和游戏间的本机桥接，含好友公开信息、局域网地址和一次房间的探测随机值，不含云服务令牌或微软令牌。消息有 ID、时效和大小限制；游戏账号必须与当前启动器身份匹配。

本版世界邀请仅支持双方正版账号，服务器仍保留 Mojang 认证，独立准入钩子只允许房主与受邀 UUID。离线身份可以加好友，但安全的混合正版/离线私密房间未实现。社交安全存储目前仅 macOS，不冒称 Windows/Linux 已完成。

## 免费网络方案及部署

选择 [e4mc](https://e4mc.link)，Fabric 26.1 已有 6.2.3 modern 版本。版本、来源和校验值在 `src-tauri/resources/performance-lock.json`，MIT 声明在 `notices/e4mc/LICENSE`。构建脚本校验下载；它是隐藏的启动器管理模块。关闭其默认自动开 relay 行为，由 Unbox 在 LAN 探测失败后显式启动。

[World Host](https://github.com/Gaming32/world-host) 的交互可参考，但本次查询没有适用 26.1 的 Fabric 发布。没有直接移植未适配版本。[Cloudflare Tunnel](https://developers.cloudflare.com/tunnel/concepts/routing/) 的非 HTTP TCP 模式需客户端代理，不当作普通 Minecraft 免费公网端口。

Cloudflare 仅部署 Workers + D1 存储好友与邀请，不传输游戏流量。20 秒同步一次，好友关系有索引；每人最多 100 个关系、注册总量暂限 2000，过期邀请/challenge 定时清理。这不是不限量服务：24 小时在线每客户端约 4320 次同步，D1 写入额度可能先耗尽。

**2026-10-08 已通过 Cloudflare 插件完成部署，全程未使用浏览器。** 用户确认 Workers Free，上传 API 也通过错误 100328 明确确认当前为 Free（免费计划不支持自定义 CPU 限制）；移除自定义 `limits` 后使用平台默认免费限制，未升级计划。

- Worker：`unbox-client-friends`；[健康检查](https://unbox-client-friends.printoria-studio.workers.dev/health) 返回 HTTP 200、`configured: true`。
- D1：`unbox-friends`，真实绑定保存在 `cloudflare/social-wrangler.jsonc`。未修改已有 `printoria` 资源。
- 每小时清理过期邀请与 challenge，关闭 Preview URL 与持久 Worker 日志。
- `src-tauri/resources/social-config.json` 已写入真实服务地址；新打包的 macOS `.app` 内也核对了该地址。

后续更新用插件 API 上传 `social.mjs` 并保留 DB 绑定和定时任务；若未来使用已登录的 Wrangler，可执行 `wrangler deploy --config cloudflare/social-wrangler.jsonc`。数据库已存在，不再重复创建。修改 schema 时先审查迁移，再使用对应 D1 query API 或 `wrangler d1 execute unbox-friends --remote --file cloudflare/social-schema.sql --config cloudflare/social-wrangler.jsonc`。

只使用免费计划；配额耗尽时应报错停止，不自动升级、绑定付费中继或启用费用兜底。e4mc 是第三方免费公共服务，不能承诺覆盖所有网络、延迟或永久可用。
