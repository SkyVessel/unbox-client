# 0.2.8 测试更新发布

2026-10-17，用户授权发布本轮生存功能修复与 Minecraft 26.3 支持。已公开发布 [v0.2.8](https://github.com/SkyVessel/unbox-client/releases/tag/v0.2.8)，GitHub latest 指向此版本。源码提交 `d8ef38027cb50660676fd1d270f95b3e550518f1` 已推送 main，发布标签指向该提交。

## 发布内容

包含文档 29–36 的启动器/皮肤库修订、Right Shift 设置、原生生存模组集成、持久地图、墓碑、Freecam 修复及 26.3 双加载器支持。继续支持 26.1 / 26.1.2，六份模块分别原生编译。

- macOS ARM64：`Unbox.Client_0.2.8_aarch64.app.tar.gz`，25,014,847 字节。
- Windows x64：`Unbox.Client_0.2.8_windows-x64-setup.exe`，13,247,476 字节。
- 两平台 `.sig`、`latest.json`、`SHA256SUMS.txt` 与六份游戏模块，共 12 个附件。
- 沿用 0.2.7 updater 公钥，私钥只在本机签名，未上传到 GitHub/CI。
- 延续测试构建模式，macOS 采用本地 ad-hoc 签名；没有 Apple 公证或 Windows 发布者证书，不提供 Intel Mac/Linux 包。

## 本次验证

- Node/浏览器 43 项、macOS Rust 65 项通过。
- Windows Actions [39019867991](https://github.com/SkyVessel/unbox-client/actions/runs/39019867991)：65 项原生测试、六份模块下载及 SHA-256 校验通过，NSIS 安装包成功生成。
- 最终 0.2.8 Fabric/NeoForge 26.3 模块各通过 25 项真实游戏标题页回归。此前生存各 23 项、视觉各 74 项、Fabric UI 139 项以及双客户端模组/材质/光影同步，见文档 36；没有将版本号修改后的标题页回归称为重新完成全部联机实测。
- 最终 Fabric 26.3 JAR 与之前完整 UI 实测 JAR 仅版本元数据不同；NeoForge 与之前生存实测 JAR 仅版本元数据和测试夹具的鼠标编号修正不同，生产类一致。
- 两平台更新包解压后均核对六份模块与最终构建 JAR 完全一致。macOS 原打包的资源签名检查失败后，重新施加 ad-hoc 签名、重打包并重签更新包；最终归档解压后的 `codesign --verify --deep --strict` 通过。
- 发布前，GitHub 草稿 12 个附件齐全，远端 SHA-256 与本地清单一致。
- 发布后，不携带登录凭证请求 latest API、latest.json 和全部清单附件，均成功。macOS/Windows 更新包与本地产物逐字节一致，使用客户端内置公钥验证签名通过；篡改一个字节均被拒绝。
- 证据：`research/verification/2026-10-17-release-028/`。

同事可通过 Settings → Updates → Check for updates → Install and restart 更新，安装前关闭 Minecraft。应用更新不覆盖独立数据目录中的 Profile 与存档。双方应更新后一起使用新版功能。

本次验证了公开更新发现、下载、签名及包内容；未在同事电脑执行应用自替换，未进行 Windows 游戏实玩、异地家庭网络或双微软账号测试。NeoForge 26.1 的 IPN/VeinMiner 上游限制仍保留；NeoForge 26.3 使用 Sodium 0.9.3-beta.1 解决上游兼容问题。
