# 0.2.8 测试更新发布

2026-10-17，用户授权发布生存功能修复与 Minecraft 26.3 支持，目标为 macOS ARM64、Windows x64，沿用已有更新公钥。

本次包括文档 29–36 的启动器/皮肤库修订、Right Shift 设置、原生生存模组集成、持久地图、墓碑、Freecam 修复及 26.3 双加载器支持。现阶段完整游戏实测范围见这些文档；不将 Windows 构建等同于 Windows 游戏实玩。

发布准备：六份游戏模块已更新版本号为 0.2.8 并编译；Node 43 项、macOS Rust 65 项通过。macOS 更新包及 Windows Actions 正在构建，尚未公开发布。最终附件、运行记录和匿名更新验证将在发布完成后补齐。
