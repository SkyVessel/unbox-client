# 26.3 HUD 编辑入口与自动保存

日期：2026-11-12。按用户要求进行小范围交互修订，保持现有两种配色与响应式布局。

- 快捷菜单原 Resume 位置改为 Edit HUD，播放图标改为移动布局图标；删除中央模块按钮下方的重复 Edit HUD 按钮。仍需进入世界后才能编辑 HUD。
- 删除 HUD 编辑器的 Cancel / Snap / Reset position / Done 操作条，界面不注册按钮；保留拖动、角点缩放与方向键微调，吸附沿用原默认行为。
- Esc / Right Shift 保存后直接退出编辑器，在世界中返回游戏。移除此前 Esc 撤销布局的快照恢复逻辑；界面被替换或关闭时也保存当前位置和大小。
- 顶部只保留操作说明，包含 Esc 保存退出提示。
