2026-10-21，[GitHub Release](https://github.com/SkyVessel/unbox-client/releases/tag/v0.2.18) 已发布为 latest，供 macOS ARM64 / Windows x64 启动器更新。

源码与两平台构建提交：`9d4c909019ad430430ea6efbfc4e10ce27a7d335`。六套模块版本均为 0.2.18。包含本轮 Discover 入口、分组分类、Modrinth 安装、皮肤库与墓碑修复，以及 `342636a` 的联机整合；先前 Logo 修复也在提交历史中。
