# NeoForge 启动修复与最近好友 Profile

2026-10-20，独立分支 `codex/join-startup-profile`。本轮为本地实现与测试，未发布新版本。

## 崩溃与修复

使用 0.2.16 原始 NeoForge 26.3 模块，在启动前写入带 `accountUuid` 的有效自动加入记录，真实复现了截图里的空指针。调用链为 `NeoForgeEntrypoint → UnboxClient.initialize → SocialBridge.init → Minecraft.getInstance().getUser()`。

NeoForge 构造模组时游戏单例尚不存在。修复后初始化阶段仅注册功能；首次建立标题界面或客户端 tick、且游戏与账号对象已就绪时，才恢复一次自动加入。有效记录显示加入进度；过期、账号不匹配、JSON 损坏或字段格式错误的记录会被清理。取消恢复仍返回标题界面并清除待加入状态。

## 最近联机配置

- 好友联机创建/准备的配置保存在玩家 Profile 列表，名称为 `Last played · 好友名称`，方块图标右上角显示好友头像。
- 每位好友只保留一项可见配置。再次接受邀请或完成同步后替换相应列表记录，刷新好友名称、头像、世界名和环境信息。
- 原有共享配置在启动器读取时按好友归并；个人 Profile 保留。切换游戏版本或加载器时采用对应的独立目录，旧目录保留用于缓存和数据恢复，避免跨加载器混用 JAR 或误删文件。
- 模组和资源包仍通过既有清单校验与同步替换；个人按键、HUD 和其他个人设置沿用原有保留规则。
- 旧界面延迟保存设置时，以后台的最新好友配置为准，防止过时条目重新出现。同一 ID 的信息更新后，界面会重新读取。
- Profile 是已准备的联机环境快照。选择后可以启动该环境；加入好友世界仍需要有效邀请与正常连接，列表条目不会永久授予访问权限。
- 该记录在接受邀请、准备配置时更新，不是仅统计成功进入世界的历史。没有可用头像时显示现有方块占位图标。
