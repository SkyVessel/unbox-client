# 0.2.22 模组安装兼容修复

2026-11-01。[Unbox Client 0.2.22](https://github.com/SkyVessel/unbox-client/releases/tag/v0.2.22) 已发布，提供 macOS Apple silicon / Windows x64 启动器更新，修复 Windows 0.2.21 安装 WorldEdit 7.4.6 时的 JSON 控制字符错误。

## 根因与修复

- Spatial GUI 1.8 Fabric 描述含未转义换行。安装器扫描现有 JAR 时的严格解析报错，阻断无关项目安装。只在内存中转义 JSON 字符串中的 LF / CR / TAB，保留其他格式错误与大小限制；不改写 JAR、不忽略身份校验。列表显示和共享模组验证使用同一解析器。
- WorldEdit 通用 JAR 同时在 Fabric / NeoForge 元数据中声明 worldedit。只对单个 JAR 提取出的 ID 去重，继续拒绝两个不同 JAR 的同 ID 与别名冲突。
- Fabric 元数据错误包含具体 JAR 文件名。

## 静默验证

- macOS Rust 86 项通过，3 项显式测试默认忽略。
- 另行执行原始公开 JAR 的回归：既有 Spatial GUI 不阻断 WorldEdit 安装；安装前后两个 JAR 字节一致；重命名第二份 WorldEdit 仍被拒绝。
- 回归覆盖换行、回车、制表符、已有转义、Unicode、错误转义、截断 JSON、其他控制字符、超大描述、两个新 JAR 的重复 ID、错误文件名与失败前零写入。
- 前端编译与六套原生游戏模块 bundle 检查通过。游戏模块沿用上一版，不改变游戏代码或模块版本；本次修改为启动器安装器。
- 使用独立临时测试 Profile，没有打开可见启动器或游戏，没有改动玩家存档。
