# 0.2.2 调试测试版

用户要求先测试功能，使用保留 DevLogin 的调试版，并确认 GitHub Release 提供 Windows 下载。此前 0.2.0、0.2.1 只有 macOS ARM 包，且正式构建禁用 DevLogin。

## 账号和好友

0.2.2 使用 `tauri build --debug` 打包生产前端资源，启用现有的开发登录入口，保留原有身份认证，不伪造 Microsoft 身份。Microsoft ↔ 已注册 Unbox 账号的双向请求、接受、列表和私密邀请增加了服务端回归测试。仅输入昵称的 Local play 与 Unbox 邮箱注册账号不同。

macOS 继续使用 Keychain。切换二进制后系统可能要求用户重新授权读取原来的钥匙串账号，不能绕过系统授权。

## Windows

新增当前 Windows 用户范围的 DPAPI 加密存储，用于账号保险库和好友身份。磁盘只存放密文，区分账号上下文；不启用 machine-wide 解密。覆盖加解密、上下文错误、篡改、文件重载与覆盖测试。

来源：[Microsoft CryptProtectData](https://learn.microsoft.com/en-us/windows/win32/api/dpapi/nf-dpapi-cryptprotectdata)。

Windows 构建使用仓库内的 GitHub Actions 工作流，在 Windows 标准 runner 上测试并生成 x64 NSIS 安装程序。游戏客户端 JAR 从同版草稿 Release 下载并按输入 SHA-256 验证，私钥不发送到 CI；安装包回到本机签名后上传。公开仓库的标准 runner 属于免费用量，见 [GitHub runner 文档](https://docs.github.com/en/actions/how-tos/write-workflows/choose-where-workflows-run/choose-the-runner-for-a-job)。

需要安装 Java 25，启动器检查 JAVA_HOME 和 PATH。尚未宣称 Windows 游戏内实玩或异地双机测试完成。

## 2026-10-08 测试中发现的问题

- 用户真实 Microsoft 账号已越过正式版 DevLogin 限制，但好友区域出现 `Invalid redirect value`。原因是线上 Worker 的 Mojang 会话验证请求使用了 Workers 不支持的 `redirect: error`。改为 `manual`，保持拒绝非成功响应，且不跟随重定向；新增 302 拒绝及正常认证回归测试。
- 本地账号/好友 11 项回归通过，Wrangler dry-run 打包通过。Cloudflare 插件重连后已部署到原有 Worker（deployment `46379b869d704c9cad6523c7535b8501`）。线上 health 与 challenge 返回 200，无有效 Mojang 会话的注册返回预期 401，已消除 redirect 运行时错误；用户真实账号的好友码画面仍待确认。
- Windows 首次原生测试发现根路径 `/absolute.jar` 未被拒绝。下载路径校验改用 `has_root` 并增加 Windows 根路径、驱动器相对路径和 UNC 路径回归。Windows DPAPI 两项测试已通过。
