# 0.2.16 联机与性能更新发布

2026-10-20，[Unbox Client 0.2.16](https://github.com/SkyVessel/unbox-client/releases/tag/v0.2.16) 已作为 GitHub latest 发布，macOS ARM64 与 Windows x64 均可通过启动器更新。

## 合并内容

- `codex/multiplayer-flow`：包含上一轮模组状态优化、性能测试器，以及邀请弹窗、好友世界列表、加入进度、同步/重启确认和连接诊断。
- `codex/logo-scale` 的 `d781738`：统一启动器、游戏内 UI 和头顶名牌的 Logo 变体比例；未改动原始图案。
- 两分支在 `codex/release-0.2.16` 完成合并，已快进合入 main。发布标签和两平台构建源码均为 `6501d0bb42c03b1bc2909a8a448807bf49424da5`。
- 六套原生模块保持 Minecraft 26.1 / 26.1.2 / 26.3 × Fabric / NeoForge，模块版本为 0.2.16。

详细行为与前序测试见 [性能优化](55-模组开关优化与性能测试器.md) 和 [联机流程](56-联机流程与异地测试.md)。

## 服务端

邀请轻量查询接口已部署到现有 `unbox-client-friends`，部署 ID `092c0821064a4725bda8ae407d8d7e97`。保留原 D1、管理员密钥绑定和兼容日期，不执行数据库迁移，不新增收费资源。

线上检查确认：健康接口正常、未认证查询返回 401、本地测试身份完整同步返回 `invitePolling: true`、认证邀请查询正常。测试身份已删除并复查不存在。单次空邮箱查询包含连接建立约 1.34 秒，不代表实际邀请到达时间或游戏延迟。

## 更新与验证边界

退出 Minecraft，在启动器更新入口确认安装；也可进入 Settings → Updates 检查更新。无需重新创建 Profile。

Windows 已完成原生测试与构建，尚无 Windows 游戏实玩记录。异地双网络持续游玩仍待实测；当前跨公网使用既有加密中继，未启用跨公网 P2P。Apple 开发者签名及公证尚未配置。
