# 账号与皮肤闭环（2026-10-07）

## 实现范围

启动器直接完成设备码认证 → Xbox Live → XSTS → Minecraft token → Java 所有权检查 → 玩家资料/皮肤 → macOS Keychain 保存 → 更新账号卡片与 3D 预览。不是把 DevLogin JAR 放入游戏，也不依赖游戏先启动。不读取或生成 `.devlogin` 明文令牌缓存。

开发构建的账号弹窗提供 `Application setup → Use DevLogin for development`。该入口需主动选择，微软授权界面会显示 DevLogin。发布构建拒绝该开发 ID；正式 Client ID 通过同一配置入口设置。DevLogin 官方将其定位为开发工具，本实现不声称获得了将该 ID 用于 Unbox 正式公开分发的授权。

Client ID 是公开应用标识，不是用户令牌。每个保存的账号以 Client ID + Minecraft UUID 区分。改用 Unbox ID 后，旧账号保留并显示 `Sign in again`，必须重新授权；不把旧应用的刷新令牌转用于新应用。正式应用仍需 Microsoft/Minecraft Services 审批和个人账号设备码流程配置。

## 用户操作

1. 右上角账号 → 配置应用（开发者首次使用）→ `Sign in with Microsoft`。
2. 复制设备码，点击 `Open Microsoft`，在微软页面完成登录授权。启动器按服务器给定间隔等待，支持取消、超时与慢速轮询。
3. 成功后立即更新账号名、脸部头像、Classic/Slim 模型和皮肤。可以再次登录添加其他账号；点击列表账号切换，移除按钮只删除本机保存，不注销微软账户、不撤销微软网站的应用授权。
4. `Skins → Choose PNG` 选择文件，仅在本地预览。选择 Classic/Slim，点击 `Apply skin` 才上传。修改的是正版账号全局皮肤；已运行的游戏建议重新进入世界。
5. `Refresh` 获取最新资料/皮肤；下载失败有已有缓存时标记缓存。上传失败保留当前保存皮肤，不把预览冒充上传成功。服务已修改但 Keychain 写入失败会明确要求刷新。

PNG 限制为静态 64×64 或 64×32、1 MB 内；64×32 仅 Classic。前端校验便于反馈，Rust 端再次完整解码校验尺寸、模型和动画格式。纹理下载只接受 Minecraft 官方纹理域名，不向纹理服务器发送令牌。

## 存储与启动

- `dev.unbox.client.microsoft / accounts-v2` Keychain 项目存储多个账号、令牌、到期时间、公开资料与当前选择。本地身份也记录选择，但不获得正版认证。
- 自动迁移旧 `primary` Keychain 账号；移除账号时清理旧项，避免旧凭据被重新迁移。
- `state.json` 可存公开账号资料/皮肤，不存访问令牌或刷新令牌。启动器不信任前端写入的账号认证状态，启动与保存时以 Keychain 为准。
- 令牌刷新串行执行；微软返回轮换后的刷新令牌时，先保存，再访问 Xbox/Minecraft，减少后续网络故障导致丢失新刷新令牌的问题。
- 登录取消、切换账号和修改应用配置都会使旧认证流程失效，迟到结果不能覆盖新选择。
- 每次启动在准备文件前确定账号；下载期间切换账号不会使本次启动串号。认证失败不会静默降级为离线账号。开发 CLI 验证流程使用独立的明确本地测试身份。
- Keychain 拒绝访问/损坏时明确报错，不回退到明文存储。目前安全存储仅支持 macOS；未验证 Windows/Linux。
- 这里不需要 Cloudflare：认证直接连接微软/Xbox/Minecraft，令牌不经过自建云服务。

## 验证与仍需实测

- Rust：17 项通过。包括多账号存储结构往返、切换/移除、Client ID 隔离、公开 IPC 数据无令牌、PNG 损坏/尺寸/模型校验、错误信息脱敏。
- 本地 HTTP mock 使用真实 reqwest 请求，验证刷新、Xbox/XSTS/Minecraft 链中各阶段令牌、所有权/资料请求及皮肤 multipart 上传；包含错误账号 UUID 与失效授权拒绝。
- Node/Playwright：13 项通过。包含模拟微软登录/取消、账号切换/移除、换应用重新授权提示、预览不上传、上传失败保留原皮肤、上传与刷新针对所选账号、启动读取失败后的错误提示与重试。
- React/TypeScript/Vite 构建与 macOS debug `.app` 打包通过。皮肤模型渲染按需更新，不运行持续动画。
- 原生桌面实测：旧本地身份恢复、开发提供方配置保存、真实 Microsoft 设备码获取与取消成功。未提交微软账号授权，也未修改真实账号皮肤。
- 以上模拟认证和本地测试不是实际微软登录。真实微软授权、Keychain 授权交互、外部皮肤修改、有效会话进入正版服务器仍需真实账号确认。没有声称审核已通过或 DevLogin 远程服务永久可用。
