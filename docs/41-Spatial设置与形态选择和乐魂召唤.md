# Spatial GUI 设置、方块形态选择与乐魂召唤

范围：26.1 / 26.1.2 / 26.3，各自 Fabric / NeoForge。保留启动器、现有模组卡片及其他功能。

## Spatial GUI

修复原先每隔数个 tick 单向覆盖原生配置的逻辑。

- 右 Shift 的已有选项与原生配置双向同步，并保存到各自配置文件。
- 新增“跟随当前人称”、背包第一人称、容器第一人称、第一人称准星光标、指定人称禁用、隐藏快捷栏。
- 开启自动跟随人称时，手动人称选项变灰；关闭自动跟随后可分别指定背包和容器人称。
- 设置页提供 **Advanced Spatial GUI settings**，打开原生完整设置。保存返回时立即刷新右 Shift 的控件状态。
- 保留未在 Unbox 面板中列出的原生高级配置，不再清空原生界面名单。Unbox 自有菜单通过单独的界面判断保持原布局。
- 原生透明度值保持精度，Unbox 百分比显示不会反复覆盖它。

## Block Shapes

默认仍为按住 V 加滚轮；快捷键可修改。

1. 按住快捷键时，在屏幕中央显示当前材质的全部可切换形态。
2. 滚轮移动高亮，预览期间不修改手持物品。
3. 松开快捷键，才提交选中的方块。

使用原版游戏模式切换器的格子与选择框素材，显示物品名称、滚轮和松键提示。只在创造模式生效。打开其他界面、世界或手持物品发生变化时取消选择，避免将旧选择提交到新的物品上。不复制容器内容或旧方块状态。

## Happy Ghast

右 Shift → Happy Ghast 新增 **Call Happy Ghast**。点击后关闭面板，方便观察乐魂飞来。也可绑定召唤快捷键，默认未绑定。

- 召唤范围是以玩家坐标为中心的立方体，设置控制边长，最大 **15 × 15 × 15 格**，即每个轴向正负 7.5 格。
- 选择范围内最近的成年、存活、未载人、未被拴住且启用 AI 的乐魂；没有目标时显示提示。不会凭空生成乐魂或传送它。
- 使用原生飞行控制向召唤者靠近；到达附近后等待，默认 **4 秒**，可设置 **1–30 秒**。
- 等待结束后恢复原生行为。玩家与它交互、登乘、离开、死亡或房主关闭功能时终止临时召唤。
- 飞行超过 10 秒仍未到达也会解除召唤；不会强行穿越障碍。原有 AI、拴绳和骑乘规则保持有效。
- 房主保存范围和等待时间；访客可以使用召唤按钮与自己的快捷键，不能覆盖房主规则。
- 请求包不携带玩家身份、目标或距离参数，由房主从真实发送者和世界实体中选择目标，并限制范围。普通服务器不启用此功能。

## 验证与交付

六种组合分别通过 68 项真实游戏检查并正常退出，测试模块与本地应用模块一致；Node 测试 43 项通过。26.3 Fabric 和 NeoForge 均通过同机双客户端 LAN 测试，覆盖访客实际召唤飞行、房主关闭功能与普通服务器重连限制。

最终结果归档到 `design/validation/client-polish-2026-10-18/`。验证包括真实原生人称渲染、设置往返、选中框松键提交、乐魂实际飞行与四秒等待，以及双客户端召唤请求与房主开关。

本轮只更新本地 macOS 调试包，不发布 GitHub Release；不将同机双客户端测试描述为异地网络或 Windows 实机测试。
