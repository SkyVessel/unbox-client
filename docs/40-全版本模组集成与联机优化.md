# 全版本模组集成与联机优化（2026-10-18）

本轮支持 26.1 / 26.1.2 / 26.3 × Fabric / NeoForge。右 Shift 模组目录共用同一份源码，六组均安装实际依赖；没有用不可用卡片补齐数量。保留原来的启动器 News、Profile 配置与透明模组卡片风格。新功能默认由玩家开启；房主功能按世界保存。

## 功能与操作

所有新增模块均有右 Shift → Mods 卡片和设置页。

| 模块 | 操作与设置 | 使用范围 |
|---|---|---|
| Mouse Tweaks | 背包内拖动、收集、滚轮移动；分别设置右键拖动、左键拖动、收集、滚轮；启用其滚轮时避免 IPN 同时处理 | 客户端；使用原版背包操作 |
| Easy Shulker Boxes | 潜影盒内容预览、数量、容量提示、嵌套提示和滚轮方向；使用原模组的容器操作 | 单人或安装客户端的房主联机，由房主控制；普通服务器禁用 |
| Status Effect Bars | HUD/背包状态时长条开关、粗细、背景颜色与透明度 | 客户端 |
| Bookshelf Visualizer | 准星查看雕纹书架的书籍信息；缩放、罗马数字附魔等级 | 客户端 |
| Resourcify | 设置页 Browse resource packs → 原版资源包页的加号 → 在线浏览；支持资源包、数据包、光影、世界分类开关和图片设置 | 浏览为客户端功能；数据包/世界仍按原版加载与权限规则 |
| Spatial GUI | 物品栏和容器在世界中显示；HUD、模糊、透明度、过渡时间可调 | 客户端；不作用于 Unbox 菜单 |
| Happy Ghast | 骑乘飞行速度 100%–500%；离开骑乘或关闭后恢复原属性 | 房主控制、按世界保存；普通服务器禁用 |
| Effortless Building | 默认左 Alt 打开原模组建筑轮盘；预览透明度、预览方块上限、保护方块实体、快捷键可调；保留形状、镜像、Undo/Redo | 仅创造模式；房主开关，服务端也检查创造权限 |
| Block Shapes | 默认按住 V 滚轮切换同材质形态；例如橡木原木、木板、楼梯、半砖；可改快捷键、反向滚轮、是否包含去皮木 | 仅创造模式；使用原版创造物品包，服务端仍验证创造权限 |

Block Shapes 选用 MIT 的 ColourScroller 单物品循环逻辑，独立原生 JAR 接入并配置材质组。本次没有接入其原版颜色循环、整行快捷栏编辑器；不会在生存中转换材料或改变数量规则。

修复 Resourcify 资源请求线程在退出后继续存活的问题：仅将该模组新建的后台工作线程设为守护线程，不改动其他线程池。26.3 新增的退出超时检测曾在实际资源浏览后触发；验证同时检查功能结果和进程正常退出。

补齐了 26.1 NeoForge 的 Inventory Profiles Next / libIPN 和 VeinMiner / Hotkey 缺口。实际背包排序保持物品数量及组件，连锁挖矿保留“按一下开启、再次按下关闭”的操作。

不加入 Colourful Containers GUI、Shrimp’s Immersive Interfaces、What Are They Up To。没有新增自动上坡或 Unbox 自有披风。

## 原生适配与源码

已有匹配版本的使用上游包；没有加载器转换层。

- Status Effect Bars：NeoForge 三个版本原生移植，修复效果替换和背包时长条渲染注入；LGPL-3.0。
- Resourcify：新增 26.3 NeoForge 原生目标，使用上游的预处理构建体系；LGPL-3.0。
- Effortless Building：26.1 Fabric / NeoForge 原生回移。
- 26.1 NeoForge：回移 IPN、libIPN、VeinMiner/Hotkey；另回移 Easy Shulker Boxes、Item Interactions、Puzzles Lib，因为上游标注 26.1 的现有 JAR 实际要求较新的 NeoForge。
- Fuzs 三个移植项目保留 MPL-2.0 源码。未再分发其保留权利的 PNG 美术，容器预览改用简单原创矩形和文字，其他可选包图标省略。
- ColourScroller：MIT；只适配本次需要的同材质形态循环。

`ports/` 内保留每个项目的上游地址、精确提交、许可、修改说明和构建说明。对应源码 ZIP 随应用一起打包。Status Effect Bars 与 ColourScroller 另提供独立 Gradle 构建，不要求取得 Unbox 私有源码或本机缓存。

启动器 **Settings → About → Third-party licenses & source code** 打开离线许可页面，可取得各移植包的对应源码。这里只完成本地分发准备，未发布公共 fork 或 GitHub Release。

## 联机流程

- 版本、加载器、共享玩法环境匹配时，复用当前游戏进程加入。
- 需要版本/加载器切换时，先显示准备原因和 Cancel，再向启动器提交切换请求。
- 局域网探测优先；探测失败且已有中继地址时直接使用，不重复等待中继准备。
- 重复点击 Join 不重复启动加入；取消准备不会写重启请求，取消连接后可再次加入；断线后可重试邀请。
- 只比较启用的材质包和实际选中的启用光影，资源库中未启用的 ZIP 不再触发同步。
- 首次缺少普通玩法 JAR 或共享资源仍可能需要一次重启；环境一致的再次加入不下载、不重启。没有承诺普通 JAR 热加载。
- 继续保留访客个人按键、HUD；不做整个 config/脚本目录的覆盖同步。
- 修复后台超时检查早于加入计时器初始化的竞态，避免停留在“检查局域网”。
- 支持 Kotlin For Forge 这类描述文件位于内嵌 JAR 的 NeoForge 依赖，避免房主共享清单扫描失败；启动器也会识别改名后的同类依赖，防止重复安装。

## 验证

六种组合都进行了隔离世界的真实启动和功能检查，最终每组 47 项通过：原生依赖加载、设置适配、创造模式形态切换到服务端、建筑放置与撤销、生存包拒绝、潜影盒权限、恶魂骑乘速度及恢复、世界设置保存、加入取消、重复点击、未启用资源过滤、完整安装清单扫描、实际在线资源搜索及返回、浏览后正常退出。

26.1 NeoForge 额外通过原有生存回归 23 项，包含实际 IPN 排序、VeinMiner 开关挖掘、FallingTree、物品渲染、地图缓存、墓碑死亡物品保存与挖掘回收。

Fabric 26.3 与 NeoForge 26.1 的双客户端 TCP 测试通过六项房主功能开/关/再开启同步、访客不能覆盖房主设置，以及普通服务器拒绝相同状态包。

Fabric 26.3 完整邀请测试使用两份真实游戏进程和本地账号服务：首次传输 2,101,824 字节、重启一次；同步后资源包、光影和自定义物品可用；再次加入下载 0 字节且不重启。同名账号身份隔离、房主冒充拒绝、队友死亡点及未授权传送限制也通过。

NeoForge 26.3 的同项完整邀请测试也通过：首次传输 2,101,943 字节，重新启动后实际物品和资源可用；再次加入下载 0 字节、不重启。

Node 前端/服务测试 43 项、Rust 测试 67 项通过。新增打包前检查验证六套模组目录、内嵌模块版本、移植 JAR 哈希和源码档案；Windows 工作流也接入此检查。

测试边界：游戏实测发生在这台 macOS 上，联机为同机隔离 TCP/本地账号服务；未冒称 Windows 游戏实玩、两个家庭网络或本轮云端部署已经完成。在线资源浏览的外部服务仍受网络和上游可用性影响。

原始结果在 `.cache/client-features/`、`.cache/benchmarks/newfeatures-*`；可保留的摘要及图片整理到 `design/validation/client-features-2026-10-18/`。本地 macOS 调试应用已打包并通过临时签名验证；38 个内嵌资源文件与源文件逐字节一致，测试模块与打包模块一致。
