# Logo 跨账号同步与游戏内显示修复

2026-10-19，目标版本 0.2.13。用户反馈已装备皇冠，在游戏内及朋友的好友列表仍显示基础图标。

## 原因与修复

0.2.12 保存了装备，但好友响应没有装备外观，启动器好友行和游戏姓名牌固定使用基础标志。本轮为好友同步增加 `logo`，为当前玩家与请求中的在线玩家增加 `playerLogos`，以 UUID 匹配。仅公开正在装备的有效外观，不公开他人的库存或角色权限。仍保持原 `badges` 和原生玩家识别协议。

服务端检查 Microsoft 身份、账号状态、商品启用和有效资产授权。撤销、到期、停用或切回基础图标后返回基础外观。启动器装备操作立即刷新桥接状态；其他客户端在正常同步周期读取更新。游戏姓名牌及两个好友界面读取装备，支持现有皇冠与现金；未知图标回退基础标志。皇冠外观不构成管理 API 权限。

双方须更新启动器并重启 Minecraft。已有兑换和装备记录保留，无需重新兑换。原版或旧版客户端不会显示这些新增外观。

- macOS 原生 68 项通过，前端构建通过；26.1、26.1.2、26.3 的 Fabric / NeoForge 六套模块均构建并校验。
