# 0.2.20 联机修复更新发布

2026-10-23（本地日期），[Unbox Client 0.2.20](https://github.com/SkyVessel/unbox-client/releases/tag/v0.2.20) 已发布为 GitHub latest，支持 macOS ARM64 / Windows x64 启动器更新。源码与两平台构建提交：`778029681338795371bfd1eb345662bdc1f39daf`。

## 本轮修复

- 将 UDP DATA / FEC 报文连同认证控制在 1200 字节以内，减少 VPN 和低 MTU 路径上的分片丢包。
- 移除心跳互相回复，只保留双方各自定时发送；静默测试 12 秒空闲为 24 个双向心跳。
- LAN / P2P 在加入途中连接失败时，自动尝试一次公网中继，并重新进行私密身份与共享文件检查。
- 保留取消、拒绝和过期邀请的停止行为；隔离旧连接的异步结果，避免影响新的中继连接。
- Minecraft 26.1 / 26.1.2 / 26.3 的 Fabric 与 NeoForge 六套模块均包含修复。

## 已完成的静默验证

详见 [修复记录](70-UDP包大小心跳与联机回退修复.md)。隐藏游戏验证包括 Fabric 26.1 直连中断回退、局域网端口拒绝回退、NeoForge 26.3 共享文件同步与重启后加入，以及 Fabric 26.1.2 的 36 项界面和策略检查。

本轮没有进行两台异地电脑的 Windows 房主 / macOS 访客实玩。测试没有打开可见游戏或启动器，没有改动用户 Profile / 存档。

## 用户复测清单

1. 房主和访客都更新到 0.2.20，并退出后重新启动游戏。
2. Windows 房主、macOS 访客：模组一致时接受邀请，确认正常进入世界并持续游玩至少两分钟。
3. 房主加入一个共享玩法模组，访客再次接受邀请，确认同步提示、下载、重启和自动加入完整完成。
4. 局域网、手机热点各重复一次。热点测试需确保两台电脑处于不同网络，才能覆盖不同出口网络。
5. 如果出现切换中继提示，确认随后能够进入世界；若失败，保留双方同一时段的日志和失败时间。
6. 加入过程中取消一次，确认不会稍后自动入服；重新接受邀请后应可正常加入。
