# 0.2.1 小尺寸徽章调整

用户反馈 0.2.0 账号徽章仍不够清晰。当前运行进程另有一个旧调试版，但不能据此否定用户对 0.2.0 的反馈。

这次保留原始 FORM 六段轮廓和直接 SVG 绘制，仅调整实际显示尺寸和线宽：

- 账号：20 → 24 CSS px；描边 1.8/24×20 = 1.5 → 2 CSS px。
- 启动器好友：16 → 20 CSS px；描边 1.8/24×16 = 1.2 → 2 CSS px。
- 保留 flex 垂直居中；左上角大标志与游戏内徽章不变。

WebKit 1×、2× 实际组件截图已检查，27 项 Node/浏览器测试通过。此次属于小尺寸视觉调整，不声称线条完全没有抗锯齿，也不以调大图标作为分辨率提高的证明。最终观感仍以用户显示设备上的反馈为准。
