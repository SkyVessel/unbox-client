# 游戏内 Client Mod 面板：竞品研究与实现

日期：2026-10-06。适用：Unbox Client / Minecraft Java **26.1**。

## 研究边界

本轮阅读了官方资料、查看官方游戏内截图，并分析 OneConfig v1 的真实界面和控件源码。**没有安装并亲手操作 OneClient、Feather 或 Lunar 本体**；不把官网截图当成实机测试，也不把三家的宣传性能当作独立比较结果。Unbox 的验证在本机真实 Minecraft 26.1 进程中完成，见下方验证记录。

参考的是原版 Feather，不使用 Dawn。Feather 官网现有收购提示，但保留的模组菜单与 HUD 编辑器图片属于旧版 Feather，截图界面日期为 2024-02-19；不把它描述成最新发行版。

### OneConfig 源码层面的发现

- `Mods.kt` 以注册表、收藏、分类和排序的 revision 为条件缓存过滤结果，列表变化时才重建，而不是每帧排序。
- `KeybindOption.kt` 区分录入状态与当前绑定，提供冲突提示；支持组合键与鼠标键。Unbox 本轮选择更小的键盘单键录入，冲突时不覆盖其他绑定。
- `ColorOption.kt` 有独立颜色模型，支持 HSV、Hex、透明度和动态颜色。Unbox 本轮提供 RGB 滑条、色板、Hex 校验和单独透明度滑条；暂不加入 Chroma，以免只有界面没有稳定行为。
- `HudDesignSession.kt` 按选中 HUD 处理移动/锁定/重置；HUD Settings 中的尺寸、颜色、背景、显示条件独立于模组功能。
- `TextHud.kt` 将文本更新和绘制区分开，可按内容更新频率刷新。Unbox 缓存 HUD 文本宽度，在 tick 周期刷新数字，不在每帧构建坐标格式或遍历字体测量。

这些是源码可见事实与本地设计取舍，不是“玩家满意度调查”。多家成熟客户端采用同类模式，是兼容玩家习惯的依据；仍需要用户实际使用反馈。

## 本轮交互方案

### 模组菜单

Right Shift 打开/关闭。顶部为 Unbox 原有开盒标志、Edit HUD、关闭按钮。主区沿用 Feather 的图标卡片结构，保留 All / HUD / Visuals / Controls / Favorites 和搜索。

- 点击卡片标题、图标或齿轮：进入设置。
- 点击 Enabled / Disabled：仅切换当前模组，不跳页面。
- 点击星标：收藏，收藏项排到前面；Favorites 只显示收藏。
- Performance 是已安装引擎信息和设置入口，不伪装成可热切换的性能总开关。
- 常规设置立即生效并保存；连续滑动在松开时落盘，避免持续磁盘写入。
- Reset settings 仅作用于当前模块；可 Undo reset，不清空 HUD 位置或模块开关。
- 控件支持 Tab 聚焦、Enter 操作；滑条支持方向键、Home、End。

### 设置页

功能与外观分开，右侧提供实际 HUD/准星预览。数值使用滑条，有限选项使用分段选择，布尔值使用开关，颜色使用色板 + RGB + Hex。Hex 无效时标红且不覆盖已保存颜色。颜色弹层的 Cancel/Esc 恢复进入弹层前的值，Done 保存。

Zoom 与 Freelook 的绑定可直接录入：冲突时显示占用功能，继续等待新键；Esc 取消、Delete 清空。绑定保存到 Minecraft 标准选项，仍可通过原版 Controls 修改。

### HUD 编辑

FPS、CPS、Coordinates、Armor 分别拥有位置、缩放和外观。

- 在世界画面上拖动单个 HUD；拖右下角调整尺寸。
- Snap 开启时使用 4 像素网格与屏幕中心吸附；方向键始终按 1 像素微调。
- Reset position 只重置当前选中项的布局；Done 保存；Cancel/Esc 恢复进入编辑前的布局。
- 编辑时使用装备样例并显示所有 HUD，使空装备和关闭的模块也能找到；退出后恢复真实内容和开关状态。
- 编辑不会暂停世界。模组设置面板仅在打开时使用游戏背景模糊；HUD 编辑不额外模糊，以保留定位参照。

## 已实现设置对应的真实行为

| 模组 | 本轮设置/行为 |
|---|---|
| FPS | 标签显示、100/250/500/1000 ms 更新间隔 |
| CPS | 左键/右键/同时显示，标签；1 秒窗口计数，只记录游戏内点击 |
| Coordinates | XYZ 标签、方向、单行/分行、小数位数 |
| Armor Status | 横向/纵向、剩余/百分比/两者、低耐久阈值、是否包含手持物品、空槽布局 |
| 以上四个 HUD | 独立位置、50–200% 缩放、文字色、阴影、背景色/透明度、padding、圆角、聊天/F3 显示条件 |
| Crosshair | Cross/Dot/T、臂长、间隙、粗细、中心点、黑色描边、颜色、透明度、攻击冷却提示及实时预览 |
| Particles | 总密度，暴击/烟/火焰/传送门/爆炸类型过滤；只影响新生成的粒子 |
| Auto Sprint | 模块开关、疾跑状态提示；保留游戏原有饥饿、碰撞等判定，不改变移动速度 |
| Zoom | 倍率、Hold/Toggle、平滑过渡、实际键绑定 |
| Chat | 仅聊天背景颜色/透明度、宽度、缩放、可见行数上限；不修改全局文字背景透明度 |
| Freelook | 使用已安装模块的实际 Hold/Toggle、相机模式和按键；保留服务器限制 |
| OptiFine Cape | 显示已有披风、可限制仅本人；官方披风优先，不提供披风所有权，不改鞘翅 |
| Performance | 从 Fabric Loader 读取实际引擎版本；打开 Sodium 原生设置，未安装 Sodium 时使用原版视频设置 |

Auto Sprint 名称修正了旧实现叫 Toggle Sprint、实际上一直自动按住疾跑的歧义。本轮不增加自动攻击或服务器作弊功能。

## 性能策略与边界

OneConfig 是 UI/配置层，不能直接等同于 OneClient 的 FPS 优化引擎。本轮不引入另一套 Compose/Skia UI 运行时，不复制其整个客户端架构。

现有 26.1 方案继续使用经过兼容性修正的 Sodium、Lithium、ImmediatelyFast、EntityCulling、FerriteCore 与 Dynamic FPS；UI 按实际安装状态显示版本。具体锁定版本来自 `src-tauri/resources/performance-lock.json`。

本轮额外处理：文本和字体宽度按 tick 缓存；模块筛选只在用户操作时重建；粒子类型按 class 缓存分类；100% 密度不调用随机数；面板关闭后不执行面板绘制/模糊。性能对比仍按同世界、视角、分辨率与距离进行，不承诺胜过 Feather/OneClient。

## 素材及代码使用

- Unbox 复用启动器现有 FORM 开盒标志。
- Barlow Semibold 使用随资源打包的 OFL 授权。
- 图标为 Lucide（随包保留 ISC 授权）及自行绘制披风轮廓。
- `scripts/build-game-ui-assets.mjs` 可重建这些纹理。
- 没有复制 Feather/Lunar 商标、图片或客户端代码进发布资源；没有将 OneConfig 源码移植进运行模块。

### 本机性能复测

Apple M3 Max / Java 25，2560×1440 framebuffer，render distance 12，simulation distance 8，固定世界副本及视角，关闭垂直同步，预热 30 秒、采样 45 秒。两次 inactiveFrames 均为 0。这里测的是**菜单关闭时的游戏**，不是模糊面板打开时的 FPS。

| 配置 | 平均 FPS | 1% low FPS | P95 帧时间 | P99 帧时间 |
|---|---:|---:|---:|---:|
| 基础组合 | 150.145 | 83.179 | 8.838 ms | 9.352 ms |
| 优化组合 | 345.397 | 118.297 | 6.430 ms | 7.015 ms |

基础组合包含 Fabric API、Unbox 和关闭的 Freelook，**不是纯原版**。优化组合加入锁定版本的性能模组；两次性能测量均排除 Dynamic FPS 后台限帧，完整组合兼容性由上述 UI 游戏测试覆盖。平均 FPS +130.0%，1% low +42.2%，仅为这一次本机固定场景的配置对比；没有做重复运行置信区间、复杂整合包/多人压力测试或竞品同机横评，也不能将提升归因于这次菜单换肤。

原始逐帧 CSV 和 JSON 已保存在 `research/benchmarks/2026-10-06-shift-v2/`。两次性能测量使用相同模块 SHA-256：`48665e3ad9f442f86811ffd730a444db3c88a0cf262675a8aec1c2644dc860b4`。最终构建随后增加菜单独立缩放与说明文案修正，游戏进行时的 HUD、粒子和优化引擎代码保持一致；最终构建另行通过完整 42 项游戏测试。


## 本轮未声称实现的竞品能力

本轮完成现有模块的功能与交互升级，不声称与竞品全部功能对等。Lunar 自由逐像素准星绘制/分享码、Feather 聊天分类/云端配置分享、OneConfig 多选 HUD/任意插件配置自动适配/鼠标组合键不在本轮实现范围。OptiFine 服务器可用性、真实拥有者披风展示、多人服务器规则和长期稳定性仍需对应环境验证。
