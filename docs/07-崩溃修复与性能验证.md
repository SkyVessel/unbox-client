# 创建世界崩溃修复与首轮性能验证

日期：2026-10-06。结果仅覆盖本机、Minecraft 26.1 和下述测试条件。

## 根因与修复

原始崩溃为 `UnsupportedOperationException: Attempted to retrieve active rendering plug-in before one was registered`，发生于世界渲染的 `BlockFeatureRenderer`。Sodium 0.8.7 宣告提供 Fabric Renderer，但该组合没有可用的实现。只启动到主菜单不足以发现这个问题。

升级到 Sodium 0.8.9，保留 Minecraft **26.1** 和 Fabric API 0.145.1。上游版本名包含 `26.1.1`，但其兼容元数据明确列出 26.1、26.1.1、26.1.2；不能只根据文件名判断兼容性。[上游问题记录](https://github.com/FabricMC/fabric-api/issues/5294)、[Sodium 修复说明](https://modrinth.com/mod/sodium/version/mc26.1.1-0.8.9-fabric)均支持本次判断，后者明确修复 Fabric API 0.145.0+ 崩溃及 Java 25 性能问题。

升级时先下载并校验新版本，再根据已安装清单和旧文件校验值将旧版移至 `unbox-backups/mods/`。不删除存档、不删除用户添加的模组；被改动的旧文件会中止升级并提示处理，避免误覆盖。

## 本次功能修订

- 游戏进程成功创建后，Launch 变为橘色 `PLAYING`，左侧变为双竖线图标；不再显示下载转圈和进度条。它表示运行状态，不宣称能够暂停多人服务器。关闭游戏后恢复绿色 Launch。
- 主页 Mods 列表隐藏清单管理的内置 Client Mods、依赖和 `unbox-client.jar`，保留用户添加的玩法模组。文件仍实际安装在游戏目录中，不通过删除模组来隐藏列表。
- 右 Shift 使用真实游戏按键绑定打开玻璃模组面板，支持搜索、分类、开关、模块设置及 HUD 编辑。再次按右 Shift 或 Esc 关闭。
- 准星、粒子、聊天和缩放有游戏内设置入口。HUD 仍以一个组合块移动；尚不是每个组件独立拖动。
- Freelook 开关不再覆盖上游的服务器禁用状态；关闭时恢复原视角。
- 模糊背景只执行一次。游戏内回归测试发现并修复了双重 blur 调用导致的第二个崩溃。

## 性能方法与结果

机器：Apple M3 Max，Java 25，4 GB 最大堆。游戏帧缓冲为 **2560×1440**，视距 12、模拟距离 8，无光影、VSync 关闭。每组使用同一源存档的独立副本、相同位置与固定镜头，预热 30 秒，采集 45 秒真实渲染循环间隔。两组采样期间失去窗口焦点的帧数均为 0。

| 指标 | 基础 Fabric + Unbox | 优化组合 |
| --- | ---: | ---: |
| 平均 FPS | 187.005 | 232.596 |
| 1% low FPS | 59.994 | 77.504 |
| P95 帧时间 | 10.816 ms | 10.755 ms |
| P99 帧时间 | 13.669 ms | 11.949 ms |
| 采样帧数 | 8,416 | 10,467 |

该场景平均 FPS 提高约 **24.4%**，1% low 提高约 **29.2%**。P95 变化很小，不能把平均 FPS 改善等同于所有卡顿问题都解决。

基础组包含 Fabric API、Unbox 和关闭状态的 Freelook，以保持测量代码一致；不是纯原版客户端。优化组增加 Sodium、Lithium、ImmediatelyFast、EntityCulling 和 FerriteCore。DynamicFPS 在两组测量中均排除，因为它主要用于后台节能；正常启动器仍安装该模组。测试钩子只在显式开发参数开启时记录帧时间，正常游戏不会采样或保存报告。

最初两次采样触发了原版 60 秒无输入后的 30 FPS 闲置限制，因此作废。有效轮次仅在测试进程内更新输入计时，避免把闲置限帧当成渲染能力。保留原始有效帧时间 CSV 和 JSON 于 `research/benchmarks/2026-10-06/`。1% low 定义为最慢 1% 帧的平均帧时间的倒数，平均 FPS 为总帧数除以总时间。

这是一组初步单场景 A/B 测试；不是跨设备统计，也不是 Lunar/Feather/OneClient 对比。尚未覆盖大型整合包、密集实体、长时间跑图、光影和原生 4K 全屏。没有据此声称超过其他客户端。

复现入口：`python3 scripts/benchmark.py baseline|optimized WORLD_DIRECTORY UNIQUE_RUN_NAME`。脚本复制存档，不原地加载源存档，需要已准备好的 Java 25 与游戏依赖。退出测试后原副本和原始结果均保留。

## 交互与构建检查

游戏内集成测试通过按键绑定派发 Right Shift，检查打开/关闭、搜索、进入准星设置并切换开关，导出真实渲染画面。包含 DynamicFPS 的完整安装组合也通过同样检查并正常保存退出。结果为 `research/benchmarks/2026-10-06/ui-full-stack.json`，截图位于 `design/exports/in-game/`。该测试使用隔离副本，不改写用户 Profile 的模组配置。

前端自动测试覆盖运行状态转换、配置创建、持久化、全屏尺寸往返及减少动态效果。Rust 回归覆盖升级备份和内置模组列表过滤。完整游戏功能、多人服务器和其他操作系统仍需后续验证。

当前 `Unbox Verification` Profile 已通过原生客户端的准备流程升级：新 Sodium 校验成功，旧 0.8.7 已备份且不再位于活动 mods 目录，Unbox JAR 与本次构建一致。原生主页 Mods 页已检查，不再列出内置 Client Mods。7 项 Node/Playwright 检查、5 项 Rust 检查及 macOS 打包通过。
