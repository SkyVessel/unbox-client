# 26.3 矢量 UI 交互与透明度修订

> GUI Scale 的整页缩放方案已被用户指出不符合设计，现已由 [90 号文档](90-26.3各GUIScale响应式布局修订.md) 的响应式布局替代。本文保留上一轮证据。

日期：2026-11-11。依据用户最新四张问题截图修订 26.3 Fabric / NeoForge。本轮本地交付，不发布 Release。

## 最终行为

- 只保留 White / Red、Gray / Yellow。唯一换色入口为 Mods 右上角弧线，拇指与轨迹共用曲线，拖动释放后吸附两端。旧 Light 配置归入 White / Red，运行资源不再打包 Light。
- 背景透明度范围 0–100%。好友栏、按钮、卡片与文字绘制在独立前景，不受背景滑块影响。原稿低 alpha 的实心控件按原底色合成，保留原有颜色。
- 快捷菜单透明度弧线绕中央按钮左下角；Mods 左侧透明度拇指复用旋转后的分类标签轮廓，上下箭头各调整 10%。滑块释放保存，方向键可操作。
- Logo 的浅色填充改为透明镂空，保留各路径遮挡关系，避免简单删除底色后露出重叠线。
- 移除模块开关的悬停矩形框及原版工具提示。组合按钮与分类标签使用同一矢量轮廓绘制反馈和命中；普通圆角按钮排除圆角外的命中区域。键盘焦点继续有视觉反馈。
- Mods 滚轮平滑循环，所有模块仍可搜索、收藏、开关和进入完整设置。列表纹理一次缓存，滚动只移动绘制位置，控制命中与列表一起移动。跨末尾循环后仍能点击对应控件。
- Survival / PvP 切换固定面板位置，标签轮廓平滑变形，卡片短暂交叉淡入。游戏主菜单第一次显示时整页 600 ms 淡入；Reduce motion 跳过动画。
- 用户已确认 GUI Scale 以 Auto 保持现有布局占比；较低手动档位同步缩小。模块详情页也遵循此规则，HUD 编辑继续使用游戏 HUD 坐标。

## 实现范围

改动位于 `client-mod/src/26.3`、SVG 提取脚本及菜单测试。其他版本沿用原界面。本次没有修改游戏视角输入、鼠标平滑或滤波。

静态矢量按物理分辨率缓存，卡片条带独立缓存；连续滚动不重新生成整页纹理。弧线绘制、拇指坐标和鼠标投影来自同一条路径。几何遮罩采用线性采样，滚动条带支持亚像素移动。

## 验证方式与边界

- `tests/solid-ui/SolidVisualTest.java` 在无游戏实例下读取交付 JAR 中的实际资源，检查实心区域 alpha、透明度隔离、Logo 透明孔洞、两个主题、曲线投影及标签命中。
- `SolidUiChecks` 只在带显式测试参数的独立离线 Profile 中运行。覆盖原生按下/释放、主题两端吸附、透明度保存、GUI Scale 尺寸变化、连续循环滚动和分类过渡，以及已有模块设置、搜索、好友/皮肤桥接回执流程。
- 自动化按动画实际状态等待截图，避免把中间帧当成最终画面。好友/皮肤使用隔离的模拟服务回执，不是线上账号端到端验证。
- 没有创建或进入世界，没有移动游戏视角。背景透明度的隔离由图层像素检查验证，游戏内背景实际观感留给用户测试。Windows/Linux 未实测。

## 本地复现

```sh
python3 scripts/prepare-solid-ui.py
UNBOX_MINECRAFT_VERSION=26.3 sh scripts/build-mod.sh
UNBOX_MINECRAFT_VERSION=26.3 python3 scripts/build-neoforge-mod.py
python3 tests/test_backport_sources.py
python3 scripts/test-solid-ui.py --loader fabric --name fresh-fabric-name
python3 scripts/test-solid-ui.py --loader neoforge --name fresh-neo-name
npm run tauri -- build --debug --bundles app
```

测试使用全新目录，两个游戏顺序运行。NeoForge 的隔离测试保留 `earlyWindowControl=false`，未改用户 Profile。普通启动器运行没有自动测试参数。

本地应用：`src-tauri/target/debug/bundle/macos/Unbox Client.app`。更新后需重新启动 26.3 游戏加载新模块。
