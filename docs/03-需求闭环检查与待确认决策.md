## 2. 最重要的八个决策

不需要在阅读前回答；本页用于检查后一次批注。建议按“Q1：…，Q2：…”回复。以下是建议，未收到回复前仍保持待定。

| ID | 需要决定 | 推荐草案 | 不同选择的影响 | 决定时点 |
|---|---|---|---|---|
| Q1 | 首先服务什么电脑和系统？ | Windows 首发，兼顾 macOS 架构设计 | 多系统同步首发扩大原生库、图形和安装测试 | UI 信息架构前 |
| Q2 | 第一批真实整合包/游戏版本是什么？ | 提供 2–3 个最想和朋友玩的包，以它们确定加载器 | Fabric 轻量客户端与 Forge/NeoForge 大包生态需求可能不同 | 技术原型前 |
| Q3 | 房主退出游戏后朋友是否必须继续玩？ | P0 房主游戏在线；P1 增加本机后台服 | 若必须首发，就必须同时解决服务端包、进程和资源管理 | UI 流程前 |
| Q4 | 混合身份适用于什么场景？ | 仅邀请制私密自建房间 | 公开服务器需要更完整的账号恢复、滥用管理和运营规则 | 身份设计前 |
| Q5 | “简单模组热加载”能否以受控轻量扩展为首发边界？ | 首发 HUD、提醒、快捷入口、显示效果；普通 JAR 重启 | 若要求任意现成模组热加载，需重新评估可行性与产品承诺 | 核心定位确认时 |
| Q6 | 除 Cloudflare 免费额度外，中继预算是否必须为零？ | 默认零预算，验证后披露不可达网络；不保证 100% | 若需高覆盖且稳定，可能要已有主机或单独预算 | 网络选型前 |
| Q7 | AI 使用什么来源？ | 支持外部 MCP 助手；游戏内使用用户选择的模型配置，并说明对外发送的上下文范围 | 产品承担推理费用需要预算与用量限制；本地模型有硬件门槛 | AI 设置流程前 |
| Q8 | 首发要完整 Feather 类功能库，还是优先四个核心点？ | 先四个核心点及用户点名的体验功能 | 全量体验库显著扩大兼容、规则和 UI 范围 | 首发范围确认时 |

不建议在此阶段纠结 React、Tauri、Electron 或具体脚本语言。先确定上述行为与硬约束，再让技术选型服务这些目标。

## 5. 仍然没有技术闭环的高风险事项

### R1：性能目标是否现实

缺证据：目标硬件、场景、整合包、光影，以及相对成熟优化组合的额外收益。

下一步：三基线对照实验。接受条件是测量达到已批准目标或缩小对外承诺，而不是引用其他项目的宣传倍数。

### R2：热加载运行时是否真正能停止错误代码

缺证据：沙箱选择、游戏线程接入、无限循环中止、卸载资源和 API 能力边界。

下一步：用声明式 HUD 和受限事件做最小原型，执行主文档 A08–A10。失败则缩小能力，不把任意 Java 调用包装成安全热加载。

### R3：零额外费用的网络兜底

缺证据：目标地区、穿透率、实际中继提供者、免费额度和使用条款。

下一步：用户决定 Q6/Q9，使用真实网络做验证。若没有可用中继，文档必须保留明确失败出口。

### R4：混合身份和模组数据一致性

缺证据：各加载器及目标包对玩家 UUID、皮肤、聊天和权限的处理。

下一步：双身份、同名、改名、重装、换机、离线转正版和管理员撤销测试。未通过组合不能标成支持。

### R5：共享列表能否完全自动安装

缺证据：目标包完整文件来源、第三方下载授权、服务端包、配置分类。

下一步：在全新机器从邀请复现目标包；对受限文件记录手动例外。不能拿“房主本地已经有文件”代替分发证据。

### R6：Cloudflare 真正零增量账单

缺证据：账号计划、其他项目使用量、资源可启用条件、R2/其他服务超额控制。

下一步：进入部署阶段后只读检查账号，列具体资源与限额；无法证明免费边界的路径不上线。本轮没有进行账号连接或部署。

### R7：AI 接入能否覆盖游戏内与外部助手

缺证据：模型来源、MCP 客户端支持方式、生成成本、代表任务成功率。

下一步：确定 Q7，验证一次“自然语言 → 受控扩展 → 试用 → 撤销”和一次无权限操作被拒绝的链路。

## 6. 下一轮 UI 设计的输入清单

这是状态覆盖清单，不是本轮 UI 方案。下一轮需决定如何承载这些任务，而不是机械地为每一项创建页面。

- 首次启动：邀请携带/无邀请、正版/离线、身份受限、运行时准备。
- 日常入口：继续上次世界、加入朋友、第一次创建世界。
- 房间：准备中、可加入、同步中、已进入、维护中、房主离线、已结束。
- 玩法管理：导入、已安装、草案、依赖冲突、来源限制、个人修改、新版待生效。
- 游戏内体验：模块开关、配置预览、按键冲突、服务器禁用、恢复默认。
- 性能：无样本、采集中、发现问题、建议应用、前后对照、效果不确定。
- AI：未连接、对话、需要补充信息、生成中、待应用、试用、失败、撤销。
- 热加载：个人扩展/共享扩展、立即/重载/重启、权限变化、成员准备失败。
- 世界：备份、备份失败、恢复进度损失说明、恢复中、恢复失败。
- 服务：网络备用路径、免费额度限制、凭证失效、更新失败、安全启动。

UI 的美观验收应与可用性同时进行：真实数据量、长模组名称、中文文本、下载进度、错误态、缩放、键盘操作和低性能设备。不能仅凭一张正常状态效果图宣布设计完成。
