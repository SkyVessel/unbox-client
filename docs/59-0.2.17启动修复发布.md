# 0.2.17 启动修复发布

2026-10-20，[Unbox Client 0.2.17](https://github.com/SkyVessel/unbox-client/releases/tag/v0.2.17) 已作为 GitHub latest 发布，提供 macOS ARM64 和 Windows x64 启动器自动更新。

## 本次内容

- 修复 NeoForge 从邀请启动、同步后重启时过早读取 Minecraft 账号导致的空指针。
- 清理过期、不同账号和损坏的自动加入记录。
- 最近好友 Profile、右上角好友头像、每位好友一项、更新配置及防止旧设置写回。
- 启动器版本显示改为读取 package.json，避免显示旧的固定版本号。

实现与真实游戏回归见 [docs/58](58-NeoForge启动修复与最近好友Profile.md)。本轮未调整 Worker 或生产数据库。

## 用户测试清单

1. 关闭报错的游戏窗口，通过启动器更新，重启后确认左下角显示 0.2.17。
2. 使用 NeoForge 接受好友邀请，确认能启动并进入世界；环境有差异时，确认同步重启后仍能进入。
3. 检查 Profile 列表里有对应好友的最近配置，右上角显示好友头像。
4. 让同一好友更新共享模组或资源包后再次加入，检查配置更新且列表仍只有该好友的一项。

无需手动删除联机记录或重新创建个人 Profile。Windows 完成构建及原生检查，尚无 Windows 游戏实玩结果；异地网络体验仍需用户测试。
