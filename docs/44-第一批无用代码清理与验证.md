## 删除内容

相对本轮开始时的工作区，删除 9 个文件，修改 9 个文件，代码净减少 24,269 字节。此前已有的未提交功能修改保留。

1. **不可达的启动器个人模组设置。** 删除 `main.tsx` 中旧 16 项模块目录、始终为 null 的弹窗状态、设置写入回调和弹窗分支，以及未使用的搜索/筛选状态。移除 `ModSettings.tsx`、它唯一使用的 `keyBindings.ts` 和对应的 `tests/key-bindings.test.mjs`。去掉只用于该弹窗的 `Modal.wide` 参数；现有弹窗仍输出相同的 `modal` 类。
2. **旧页面专用样式。** 删除 42 条只服务上述旧模块页、准星编辑器及宽弹窗的 CSS 规则。保留现有页面和公共控件样式，未改变颜色、布局或交互。
3. **未使用导入。** 移除七个组件的未用 React 默认导入、Friends 的未用 bridge 导入，以及主界面无用图标导入。
4. **五个停用 Java 类型。** 删除 `DroppedItemMixin.java`、`DroppedItemStateMixin.java`、`DroppedItemState.java`、`InventorySortScreenMixin.java`、`InventorySorter.java`。三个旧 Mixin 均不在实际注册表中；ItemPhysic Lite、IPN 的当前实现和 Gate Mixin 保留。
5. **旧单文件 fixture。** 删除 `tests/SharedItemFixture.java`；现行测试继续使用 `tests/fixtures/common` 和两个加载器各自的 fixture。

未删除新建 Profile 仍使用的默认配置、`mod-options.json`、`saveModules` 或游戏内按键迁移。Rust、构建脚本及原有内嵌 JAR/资源均与本轮开始时逐字节一致。旧世界接口、旧云端草案、测试源集分离和重复配置收拢属于后续批次，本轮未处理。
