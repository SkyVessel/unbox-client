# 1.21.11 / 1.20.1 原生移植进展

日期：2026-11-10。分支：`codex/port-1.21.11-1.20.1`。基线：`9e8c74c911cacec7317efecadcab59eebdf1ddf5`。

## 范围与用户决定

- 1.21.11：Fabric + NeoForge，Java 21，保留快乐恶魂。
- 1.20.1：Fabric + Forge，Java 17。用户明确放弃该版本的快乐恶魂相关功能；此例外不涉及其他模块。
- 用户随后明确 Spatial GUI 只在有公开兼容版时加入。已通过作者 Modrinth API 核实四个目标组合均有公开、状态为 `listed` 的 1.8 版；发行元数据在 `research/verification/backports/spatial-public-releases.json`。当前 Fabric 1.21.11 直接使用公开原包，不是自行移植的 Spatial GUI JAR。
- 功能、英文 UI、资源与交互以本分支起点为准。没有混入原工作目录 `codex/unpvp-ui` 的未提交改动。
- 当前为开发中的移植分支。启动器尚未开放这两个版本的 Profile；没有公开发布或更新线上好友服务。

## 实现

`client-mod/build.gradle` 使用 Loom 1.14.10 和官方映射构建 Fabric 独立 JAR，再重映射到生产用 intermediary 命名空间。1.21.11 没有复用 26.x JAR。[Fabric 的 1.21.11 迁移说明](https://fabricmc.net/2025/12/05/12111.html)明确建议这一代 Loom。

`client-mod/neoforge` 使用 ModDevGradle 2.0.147、NeoForge 21.11.48。`client-mod/forge` 使用同一工具的 Legacy Forge 插件、Forge 47.4.28，并配置 SRG 重混淆和 Mixin refmap；后者目前完成开发环境准备，尚未完成客户端源码适配。[Legacy Forge 构建与重混淆说明](https://github.com/neoforged/ModDevGradle/blob/main/LEGACY.md)、[Forge 官方 1.20.1 版本页](https://files.minecraftforge.net/net/minecraftforge/forge/index_1.20.1.html)。

共同源码仍在 `client-mod/src/main/java`。1.21.11 的 API 名称差异由 `prepare-version-sources.py` 在编译前处理；渲染与测试专用替换文件位于 `client-mod/src/1.21.11/java`。原有 26.x 生成结果保持不变。

已处理的 1.21.11 差异包括：

- GUI 渲染、键盘注册、网络 payload 注册、相机 FOV、聊天 Mixin 和墓碑裂纹渲染接口。
- Effortless Building 的加载器包名前缀，保证关闭状态和生存模式的输入/服务器权限限制生效。
- Item Interactions v1 的潜影盒权限、内容预览、数量、嵌套提示和滚轮设置接口。
- 书架可视化的 mod ID 与 owo 配置接口。
- Spatial GUI 1.8 的设置同步，并通过原版模糊通道补充该版本缺失的世界模糊设置。第一人称背包已做开关截图对照：世界变模糊，背包面板、文字和 HUD 保持清晰；其他容器与视角仍待补充视觉验收。
- 将现有 MIT ColourScroller 定制形状引擎从源码原生编译并重映射；公开原版 JAR 不提供当前客户端依赖的 `cycle` 接口。
- 固定 Wick 四个目标组合的官方文件与 SHA-1/SHA-512，见 `client-mod/wick-backport-lock.json`。文件列表来自作者的 [CurseForge 项目 API](https://www.curseforge.com/api/v1/mods/1728334/files?pageIndex=0&pageSize=50&sort=dateCreated&sortDescending=true)，源码与许可证见 [Wick](https://github.com/comedy01/Wick)。

1.20.1 的快乐恶魂入口、快捷键、实现、Mixin、网络消息和专属测试均从该版本的生成源码中移除。建筑、潜影盒、共享世界等共同检查保留。`tests/test_backport_sources.py` 验证仅移除这一模块，1.21.11 的模块清单不变。

1.20.1 的 Java 17 适配将虚拟线程替换为有名称的 daemon 平台线程，保留原有线程池大小、任务取消、超时和 socket 生命周期；同时处理 `Math.clamp` 和新版 List API。VoxLink 源码和实际 TCP/UDP 回归已使用 Java 17 编译、运行。这不代表游戏内的登录与邀请流程已完成适配。

启动器根据游戏版本选择 Java 25 / 21 / 17，仍拒绝启动未开放的目标版本。好友服务源码已接受四个正确的版本/加载器组合，并拒绝 `1.20.1 + NeoForge`、`1.21.11 + Forge` 等未支持组合；此变化只在本地测试。

## 2026-11-11 · 1.20.1 Fabric UI、小地图与 Zoom 修复

用户提供 Mods/Zoom 设置页截图，报告左侧与顶部内容被裁剪、小地图黑屏（大地图可显示），并确认 Zoom 按 C 不放大。

- **裁剪根因**：原生 1.20.1 `GuiGraphics.enableScissor` 直接使用屏幕坐标，不应用 PoseStack。共用菜单有缩放，小地图 HUD 有位移和缩放，原来的直接调用因此在错误位置裁剪。`LegacyGui` 现在先变换四角，再进入原生裁剪栈；改变裁剪前提交已排队绘制，保留嵌套裁剪交集。转换仅作用于 1.20.1，共用布局和其他版本源码未改。
- **Zoom 根因**：旧版 `KeyMapping.MAP` 每个按键只保存一个绑定；重建映射后，默认 C 与原版保存快捷栏修饰键冲突。独立启动回归先复现失败，再加入 `LegacyZoomKeyMixin`：原生分发后将匹配 Zoom 当前绑定的按下/释放状态同步到 Zoom，保留原版功能，不改相机或鼠标处理。
- **构建与证据**：Java 17 原生 `build` 通过；GUI Scale 2 和 4 各运行 6 项启动/渲染/按键检查，均通过。实际查看两种缩放下 Mods 与 Zoom 设置页截图，首行图标、左侧标签、顶部标题完整；末行按滚动容器正常裁剪。离屏测试使用真正的 `MapTileRenderer` 上传纹理，在右上角缩放后读取像素，并检查嵌套裁剪边界。按键测试覆盖默认 C、释放、改绑、旧键失效与失焦释放。
- **回归范围**：`tests/test_backport_sources.py` 4 项通过，确认六个 26.x 原生目标的生成源码仍与分支基线一致。未进行世界内视角、Zoom 手感或真实地形采集测试；这些交由用户验证。没有据此宣称完整移植完成。
- **测试隔离**：新增回归只由显式 `unbox.homeSmoke` 启动，使用独立 `production-fabric-home`；临时窗口在测试开始时隐藏，防止抢占人工试玩操作。人工入口不传该参数，也不会运行这些检查。早期可见测试窗口曾停在 Select World 而未生成报告，未算作通过。
