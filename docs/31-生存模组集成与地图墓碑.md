精确原生版本、传递依赖、模组 ID、发布 ID、下载来源、SHA-1/SHA-512 和 JAR 内实际要求记录在 `src-tauri/resources/survival-mods-lock.json`。没有转换加载器或修改上游兼容声明。NeoForge 26.1 的 IPN/libIPN 元数据要求 26.1.2，已排除并显示不可用原因。

启动准备流程读取独立的 survival 清单。下载完成并校验后再安装；受管旧版本先备份，用户自行放入的同名或同 ID 冲突文件保留并报错。共享环境排除这些受管模组，避免和房主传来的玩法 JAR 重复安装。普通 Minecraft 模组仍需在启动时加载，不承诺 JAR 热加载。

旧的自制掉落渲染、背包 Sort 按钮不再登记为运行 mixin；已有排序调用入口转交 IPN。ItemPhysic Lite 调用上游掉落渲染和旋转，IPN 使用上游容器整理、规则与快捷键。可选 mixin 为上游引擎加入 Unbox 总开关和会话限制；缺少兼容引擎时不会显示为可用功能。

## Right Shift → Mods 设置闭环

| 模块 | 设置及操作 | 生效范围 |
| --- | --- | --- |
| Dropped Items | 开关、旋转速度、经典旋转 | 个人视觉，可用于普通服务器 |
| Inventory Sort | 按钮/提示、整理是否包含快捷栏、自动补充、锁槽、滚轮移动、同类高亮、背包布局 | 单人、LAN、验证过的 Unbox 房间；普通服务器禁用 |
| Inventory Sort → Advanced settings | 打开 IPN 原生快捷键与规则设置；返回回到原 Unbox 面板 | 个人设置；基础开关继续由 Unbox 管理 |
| VeinMiner | 最大连锁数、冷却 tick、是否还需潜行、正确工具要求、官方 Hold 快捷键 | 规则仅房主修改；访客可修改自己的快捷键 |
| FallingTree | 最大树木大小、是否处理树叶、是否必须潜行 | 仅房主修改；默认站立砍树，潜行暂停 |
| Gravestones | 创建开关、名字显示距离 | 仅房主修改；关闭创建不删除已有墓碑 |
| Minimap | 缩放、死亡标记、采样预算、HUD 尺寸/位置/显示条件、全屏地图快捷键 | 个人设置；默认 M |

房主规则改变通过状态包通知访客。访客卡片显示 Host: Enabled / Disabled，隐藏房主规则编辑器，仅保留个人快捷键；不展示本地默认值冒充房主配置。未收到可信房主状态时为 Host required。普通服务器不允许靠此客户端启用玩法模组。VeinMiner/FallingTree 在房主主动开启前由引擎入口门控关闭。

Right Shift 保留为菜单入口，不能被新模组按键覆盖；其他按键仍沿用已有冲突处理。新连锁挖矿/砍树图标使用代码矢量图形，旧图标沿用。

## 自研石头墓碑

- 新墓碑为完整原版石头方块，姓名使用浮动 TextDisplay；不再以盔甲架创建新墓碑。
- 死亡正式进入掉落阶段时暂存完整 ItemStack 及组件，覆盖背包、盔甲、副手、鼠标拿着的物品；按用户“全部物品”要求包含消失诅咒物品。保留库存规则开启时不另造墓碑。
- 方块、姓名与 SavedData 记录成功建立后才清空上述库存。只找空气放置，不覆盖地形/容器；没有安全位置时保留原版死亡掉落。
- 正常世界保存与重新加载会保留内容。必须由固定 UUID 匹配的主人挖掘，沿用原版石头挖掘进度与工具速度；生成掉落物成功后删除方块、记录和姓名。
- 取回物品正常下落；针对未能立即捡取的物品保留主人与不自然消失保护。爆炸、活塞、替换、连锁挖矿和非主人操作不能直接取走墓碑内容。
- 已有旧版实体墓碑继续兼容；不迁移/删除玩家存档。未覆盖任意第三方附加装备槽，也未声称异常断电下跨世界文件事务一致。

## 自研地图

- 玩家方向箭头和当前位置；XYZ 坐标位于小地图下边外。
- M（可重设）打开大地图，拖动平移、滚轮缩放；十字定位线显示鼠标指向坐标。
- 增量采样已加载区块，不主动生成地图外区块；已采样地形按世界身份和维度后台保存。禁用地图时不继续采样，极短暂加载但尚未采样的地形不保证留存。
- 每名玩家按 UUID 只保留最新死亡，显示头像与名字；私密房间遵循 UUID 允许名单，普通 LAN 按 Minecraft 的 LAN 元数据识别同房玩家，普通服务器仅本人/计分板同队者。
- 双击死亡点仅在本地玩家具有原版作弊/管理员命令权限时发送 `/tp`，最终由服务器验证；不会赋予玩家权限。
- 当前地图展示当前维度；其他维度最新死亡仍保存并替换旧记录，进入该维度后显示。不支持通过地图跨维度传送。
- Unbox 房主世界有持久世界 UUID，供跨会话地图识别。原版远程服务器没有此身份协议，只能按服务器地址隔离缓存；服务器换图时可能需要另行清理旧缓存。
- 断线清理会话状态；正常退出请求完成后台地图写入。强制杀进程仍可能丢失最后尚未保存的采样。

## 静态依据与尚未验证部分

已读取所选官方 JAR 元数据和类签名，核对两平台的 IPN / ItemPhysic 反射接口、FallingTree / VeinMiner 原生配置与门控入口，以及两游戏版本的地图、墓碑相关接口。保存路径、设置键、网络注册和 UI 可达路径已做源码审阅。这些都不替代编译或游戏实测。

初次源码交付时待用户允许的验收清单（本轮执行情况见文档 32）：四种目标编译、启动及 mixin 应用检查；模组开关/键位/规则实际效果；单人及双人 LAN 房主同步；普通服务器禁用；墓碑死亡—保存退出—重进—挖掘—库存核对；地图探索持久化、死亡点共享、权限传送与性能。旧 `SurvivalSmokeTest` 已替换为石头墓碑和真实第三方引擎验收，历史旧结果不作为本轮证据。

本轮未集成准星目标信息（Jade）、建筑模组或披风功能；未改变启动器 News/Profile 界面。
