# Unbox Client 0.2.0 发布验证

用户于 2026-10-08 明确授权构建并发布 GitHub Release，覆盖之前“暂不构建 Release”的要求。目标为 macOS Apple Silicon，Minecraft Java 26.1；发布入口为 https://github.com/SkyVessel/unbox-client/releases/tag/v0.2.0 。

## 徽章修复

启动器账号和好友名称前复用原有 FORM 六段路径，改为 inline SVG 直接绘制，避免 WebKit 对旧遮罩的低分辨率中间栅格化。账号 20 px、好友 16 px，均使用 flex 垂直居中；WebKit 2× 截图与几何检查通过，中心偏差为 0。

游戏内好友徽章使用单独的 96 px 透明纹理，移除原大菜单 Logo 的留白，以 12 个 UI 单位绘制。原有大 Logo 保持不变。真实 26.1 游戏截图检查完成。当前没有注入玩家头顶名称徽章；不将不存在的功能描述成已修复。

## 检查

- Node / Playwright：27 项通过。
- Rust：24 项通过。
- 真实游戏好友 smoke：21 项通过，包含面板、不同 GUI 缩放、邀请身份限制、LAN 探测及拒绝未邀请玩家。
- 前端生产构建和签名 release 构建，及附件验证结果记录于本文件后续发布记录。
- 本轮没有修改鼠标输入行为，也没有以徽章修复声称 FPS 提升。

## 更新与限制

左下角无边框下载图标，以及 Settings → Updates → Check for updates 均已实现。发现新版后由用户点击 Install and restart；游戏运行期间不能安装。

更新清单与归档使用本机已有 Unbox 更新密钥签名。私钥不进入仓库或附件。此签名不同于 Apple Developer 签名，当前没有 Apple 公证。仅发布 arm64，不能用于 Intel Mac、Windows 或 Linux。

正式优化构建保留原有身份边界：DevLogin 只在 debug 中开放，release 要使用批准的 Unbox Client ID。Microsoft 审批未完成时，不承诺该版能够重新登录开发授权账号。

## 发布产物检查

- 优化 release 构建成功：`.app` 19.62 MiB，签名更新归档 11.13 MiB。
- Tauri 发布配置对整个应用执行 ad-hoc 签名；`codesign --verify --deep --strict` 通过。未使用 Apple Developer 证书或公证。
- 更新签名使用客户端内置公钥验证通过；修改归档一个字节后验证失败，拒绝被篡改的包。
- 应用与 Fabric 模块均为 0.2.0；包内 JAR 与实测 JAR 一致，包含新徽章，不包含 SharedItemFixture 测试模组。
- 原生窗口自动化遇到 macOS 截图服务错误，因此不宣称通过客户端实际自替换与重启测试。更新 IPC、安装互斥和错误恢复的已有测试通过。
