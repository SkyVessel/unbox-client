# 0.2.4：好友、游戏设置、地图与 NeoForge

后续：NeoForge 自有模组和邀请适配已继续实现，见 [2026-10-09 原生适配记录](21-NeoForge原生适配.md)。下文保留 0.2.4 当时的验证范围。

2026-10-08。本轮为本地测试版；未发布 GitHub Release。下面区分实现、自动验证与仍需真人复测的部分。

## 好友列表与皮肤

- 好友显示数据按账号标识的 SHA-256 文件名保存在应用数据目录 `friends-cache/`。首次成功同步后建立缓存，下次打开直接显示。缓存没有登录令牌、邀请密钥或可加入的旧邀请。
- 后台同步失败不清空列表；缓存里的在线状态变为 Offline，邀请与修改按钮禁用，避免误用过期状态。连接成功后恢复真实状态。切换账号不复用上一账号的缓存。没有缓存的首次登录仍需连接一次。
- 游戏内朋友头像的 `blit` API 参数是 x1/y1/x2/y2；旧代码将最后两个坐标当作宽高，导致远离原点时拉伸。现在是 x+24/y+24，保持方形。
- 私密联机握手原来以 UUID/昵称创建空 GameProfile，丢掉 textures。邀请认证完成后，现在在后台向 Mojang 查询该精确 UUID 的签名属性，等待最多 8 秒再结束登录。保留已认证 UUID 和邀请中的昵称；查询超时不会在登录完成后改写身份，也不接收访客任意提供的皮肤地址。上游不可达时仍可能使用默认皮肤。
- 官方签名皮肤接口本机探测通过；两个真实微软账号再次互访的皮肤显示仍待用户复测。本轮未读取微软访问令牌来模拟登录。

## 按键与两端设置

- 新按键覆盖原有冲突绑定，将旧绑定清空；不再因冲突停留在录制状态。Esc 取消；Delete 清空；点击其他控件也会结束录制。
- Zoom、Freelook、Minimap 的绑定在 `unbox.properties` 与实际 KeyMapping 之间同步；启动器保存的绑定在游戏中应用，Minecraft Controls 中的修改也会回写。
- 启动器设置目录由游戏 `ModOptions.java` 导出到 `app/src/mod-options.json`，包含 248 个不同选项键。脚本：`python3 scripts/export-mod-options.py`；Node 测试校验源文件摘要，防止游戏修改后忘记更新启动器。
- 补齐 HUD 外观/可见性/装备槽、14 类粒子参数、准星预设和 15×15 画布及分享、聊天布局等。拖动 HUD 仍在真实游戏中完成，启动器不伪造游戏实时画面。

## 小地图与延迟

- Client Mods 中启用 Minimap / Latency。小地图和延迟均使用现有 HUD 布局、锁定、拖动和大小调整。
- 默认 M 打开大地图，再按对应绑定或 Esc 关闭；拖动平移，滚轮缩放。
- 地图仅采样已经加载的区块，不触发加载、区块生成或网络请求。每 tick 限制样本数与时间预算，贴图最多约 5 次/秒更新；关闭地图功能后停止地形采样。
- 已探索颜色缓存在当前连接的内存中，最多 4 个维度、每维度 1024 个 16×16 色块，原始像素约 4 MiB 上限。退出世界释放。暂不提供跨游戏重启的完整地形图档案；未探索区域为空白，初次显示会逐步填充。
- 本人死亡点为红色，队友使用按 UUID 稳定选择的其他颜色。房主游戏在实际死亡事件中发送标记，客户端不能上报伪造队友死亡。共享给当前房间中支持该协议的玩家。
- 房主世界保存最近 64 个死亡标记到 `unbox-map-deaths.json`，以串行后台 I/O 写入；重新加入时同步历史。普通不带 Unbox 的服务器只能显示本人的原版最近死亡位置，无法提供所有队友历史。
- 双击当前维度的死亡标记发送正常 `/tp @s` 命令。客户端先检查权限，服务器仍会执行最终权限检查；没有作弊/OP 权限不能传送。
- Latency 使用 Minecraft 玩家列表的真实延迟，不额外创建探测连接。单人显示 Local，尚无服务器数据时显示占位。

## NeoForge 26.1

- 新 Profile 可选择 NeoForge。精确使用 `26.1.0.19-beta`，不自动升级 Minecraft 到 26.1.1/26.1.2。
- 校验固定 SHA-1 的官方安装器，在 Unbox 独立运行时目录中运行官方客户端安装流程。Maven 同组同名依赖用 NeoForge 版本覆盖，避免与原版重复冲突。
- 固定性能模组：Sodium、Lithium、FerriteCore、ImmediatelyFast、Dynamic FPS。版本与下载摘要见 `src-tauri/resources/neoforge-performance-lock.json`。部分包名含 26.1.1/26.1.2，但发布者把 26.1 列为兼容版本，本次也实际启动了精确 26.1 世界。
- 已真实完成安装、模组加载、进入世界和约两分钟运行；测试由专用脚本结束。没有使用用户自己的世界原件。
- **当前 NeoForge 支持加载器、玩法模组与这些优化模组；Unbox 自有 Client Mods、地图 HUD、私密邀请及自动同步仍是 Fabric 实现。** 创建时明确提示，相关开关不伪装可用。这部分跨加载器移植尚未完成。
- 参考：[NeoForge 26.1 官方版本说明](https://neoforged.net/news/26.1release/)、[官方安装器目录](https://maven.neoforged.net/releases/net/neoforged/neoforge/26.1.0.19-beta/)、各性能模组的 Modrinth 发布元数据。没有付费基础设施改动。

## 性能结果

2560×1440、视距 12、固定复制世界与视角，每次预热 30 秒、记录 45 秒。最终采样器限时约 250 微秒/tick（每 32 个样本检查），复用区块/色块查询，静止时完整采样间隔 1 秒。

| 最终实现 | 平均 FPS | 1% low FPS | p99 帧耗时 |
| --- | ---: | ---: | ---: |
| 地图关闭 | 757.949 | 204.765 | 3.889 ms |
| 地图开启 | 763.133 | 218.205 | 4.256 ms |

平均值与 1% low 有测试波动，不能把开启后的较高数值解释为地图提升性能；本轮开启后的 p99 仍较高。已控制采样工作量，但不承诺零开销或优于其他客户端。大范围移动、大整合包、Windows 与 NeoForge 性能仍未实测。初版对照及方法见 `research/benchmarks/2026-10-08-map/README.md`。
