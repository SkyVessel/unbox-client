# 0.2.9 更新发布

2026-10-19，用户授权发布当前客户端更新，覆盖 macOS ARM64 与 Windows x64，沿用现有 updater 公钥和 GitHub Release 渠道。

发布范围：文档 38–44 的模组集成、原生移植、联机交互、Spatial GUI 设置、创造形态选择框、乐魂召唤、披风修复与保功能代码清理。支持 26.1 / 26.1.2 / 26.3 × Fabric / NeoForge，移植源码和许可随包分发。

本文件随发布源码先记录范围；公开发布结果及附件验证将在完成后补记。当前步骤：六份 0.2.9 游戏模块编译完成，原生资源与源码分发检查通过，正在构建两平台更新包。
