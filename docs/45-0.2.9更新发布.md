# 0.2.9 更新发布

2026-10-19，已公开发布 [v0.2.9](https://github.com/SkyVessel/unbox-client/releases/tag/v0.2.9)，并设为 GitHub latest。发布标签指向源码提交 `a7448c292617dbd20aa3c157d6f8bd6cca12f823`，源码已推送 main。

## 发布范围

包含文档 38–44 的全版本模组集成、原生移植、联机交互、Spatial GUI 设置、创造形态选择框、乐魂召唤、披风修复及保功能代码清理。支持 26.1 / 26.1.2 / 26.3 × Fabric / NeoForge。

- macOS ARM64：`Unbox.Client_0.2.9_aarch64.app.tar.gz`，52,479,694 字节。
- Windows x64：`Unbox.Client_0.2.9_windows-x64-setup.exe`，31,282,471 字节。
- 两平台签名、`latest.json`、`SHA256SUMS.txt` 和六份游戏模块，共 12 个公开附件。
- 10 份移植源码归档及许可随应用分发；`ports/` 对应源码也已公开。启动器 Settings → About 可取得这些材料。
- 沿用原 updater 公钥，私钥只在本机用于签名，没有上传 GitHub/CI。

继续沿用测试构建方式；macOS 为 ad-hoc 签名，没有 Apple 公证或 Windows 发布者证书。没有 Intel Mac/Linux 更新包。

- 六份 0.2.9 模块重新编译；原生功能集、模块版本和内嵌资源校验通过。与此前各 68 项游戏检查的六份 JAR 比较，差异限于披风类/调用入口、停用代码删除、Mixin 配置和版本元数据，其余条目逐字节一致。
- macOS 应用及解压后的更新归档均通过 `codesign --verify --deep --strict`；45 个内嵌资源文件与本地发布资源完全一致。
- Windows Actions [39200582747](https://github.com/SkyVessel/unbox-client/actions/runs/39200582747) 基于发布源码提交构建，67 项原生检查通过，NSIS x64 安装包生成成功。
- Windows 安装包解压核对 45 个资源文件。全部 JAR、源码 ZIP 等二进制资源逐字节一致；9 个 JSON 文件仅因 Windows Git checkout 的 CRLF 换行符不同，规范化换行和解析后的配置内容均一致。
- 10 份源码 ZIP 中的 5,022 个文件条目与本地对应源码一致。保留上游源码和许可原有空白/换行，没有为消除 whitespace 提示改写这些文本。
- 草稿阶段确认 12 个远端附件的 SHA-256 与本地一致，标签目标提交正确，再公开发布。
- 发布后不携带 GitHub 登录凭据，成功获取 latest API、latest.json 和全部 12 个附件。下载文件 SHA-256 全部匹配，两平台包使用客户端现有公钥验签通过；篡改一个字节均被拒绝。
- 证据保存在 `research/verification/2026-10-19-release-029/`。

披风修复按用户要求没有游戏或网络功能复测，未验证真实持有披风账号的显示。此前六组合游戏检查、双加载器同机 LAN 测试及清理后的 42 项 Node / 67 项 macOS Rust 检查仍按原文档范围记录。本次公开附件验证不等于 Windows 游戏实玩、两个家庭网络实测或同事电脑上的应用自替换验证。

## 更新方式

先关闭 Minecraft，再使用启动器 Settings → Updates → Check for updates → Install and restart。双方都应更新后使用新版联机功能。Profile 和存档保存在独立数据目录，应用更新不覆盖这些目录。
